## 0. 一页结论

| 问题 | 结论 |
|------|------|
| 两个方向选哪个 | **方向 2：AI 销售 + AI 经营 + AI 采购**。在供大于求、库存收缩 1/3、需求碎片化的市场里，客户只为「多接一单、少亏一单」付费；方向 1 的「运营」是改善型需求 |
| 方向 1 里有价值的部分怎么办 | **沉睡客户激活、精准跟进话术**并入「AI 销售」的跟进层（已在获客模块中设计完成）；只放弃「内容生产 / 社群运营」，留作第二年增值包 |
| 爆点功能 | **「秒报价」= 一句话识别需求 → 配货比价 → 拼车 / 直发 / 自提 → 带毛利的报价 → 守门 → 一键发出 → 自动跟单**。把 AI 销售的自动报价和 AI 采购的配货比价焊成一个动作 |
| 同行报价拿不到 | 第一阶段比价不追求「全市场最低」，而是「这单从哪拿货最划算、报多少客户大概率接受」：自有库存 + 上游当日报价 + **货袋子平台货源** + 市场指数 + 客户历史成交价足够；平台货源天然就是同行报价网络 |
| 小单没车配货 | 报价引擎不输出价格，输出**接单方案**：专车 / 市区配送（整单一车）/ 拼车窗口 / 货源直发 / 客户自提 / 替代规格 / 部分报价，到岸价含运费、起订量、账期；不经济的单由守门规则拦下，不报或报「调货价 + 交期」 |
| 管型材（量小而杂、很多小管件）适不适合 | 主线适合，参数和三个模型要换：支 / 米 / 个计量与理重换算、市场内档口调货 + 整单一车市区配送、管件按毛利率定价；已作为引擎的「第二套参数包 + 解析器扩展」实现（02 分册 §16，演示询价 Q7） |
| 一期范围 | 只做「秒报价」一条线 + 经营看板两张卡；渠道目录与 SOP 直接复用获客模块；个微 RPA 退为可选 |
| 定价 | 按吨：成交后每吨 1–2 元或按月包量，不按席位 |

## 3. 待确认决策点

| # | 问题 | 建议 |
|---|------|------|
| Q17 | 爆品方向 | **方向 2**（销售 + 经营 + 采购），运营能力并入销售跟进层 |
| Q18 | 一期是否接客户 ERP / 进销存的库存 | **A** 一期以「手工维护 + Excel 导入 + 出库自动扣减」为主，预留金蝶 / 用友 / 钢贸常用进销存接口；**B** 一期即做 ERP 对接。建议 A，先跑通报价闭环 |
| Q19 | 上游报价如何进入系统 | **A** 销售把上游每日报价（微信 / 表格）投喂给系统，AI 抽取；**B** 由采购员在「货源」页手工维护；**C** 两者都要。建议 C，以 A 为主 |
| Q20 | 平台货源是否允许作为报价货源 | **A** 允许，并按平台服务费计入到岸价（形成撮合收入）；**B** 一期只用自有 + 上游。建议 A，这是平台的差异化与第二曲线 |
| Q21 | 自动发出的默认边界 | 建议默认：A/B 级客户、金额 ≤ 15 万、每行毛利 ≥ 25 元/吨、全部货源报价 6 小时内、无逾期 / 无替代规格；其余需确认。商家可下调不可上调（护栏不可配） |
| Q22 | 定价模式 | **A** 按成交吨位 1–2 元/吨；**B** 按月包量（如 3,000 吨/月封顶）；**C** 基础席位费 + 吨位。建议 B 为主、A 为试用期 |
| Q23 | 管型材商是否进入一期种子客户 | **A** 一期只做建材 / 板材商，管型材二期；**B** 一期各选 2–3 家，两套参数包同时回放。建议 B：管型材商单量多、开单痛点更强，是「一句话开 20 行单」的最佳演示场景；但按吨计费对管型材要换成按单 / 按行 |
