> 版本 v0.9 · 2026-10-03 · 实现：`prototypes/ai-acquisition/shared/quote-engine.js`（规则模拟）+ `shared/quote-data.js`（演示数据与参数默认值）

## 0. 引擎做什么、不做什么

**输入**：一条询价（原文 + 客户）＋ 当前数据（库存、外部货源报价、物流价表、拼车窗口、市场指数、客户信用与历史价）＋ 参数。  
**输出**：解析后的询价行；若干**可交付的接单方案**，每个方案 = 每行的（货源 × 交付方式 × 到岸成本 × 报价 × 毛利 × 到货时间）+ 守门结论 + 得分 + 发出后动作；一个推荐方案；客户视角的报价单文本。

**不做**：不预测行情、不自动改库存成本、不替代经理做信用审批、不在客户未提自提时主动推荐自提。

处理顺序（与代码函数一一对应）：

```
parse(原文)  →  options(每行 × 货源 × 方式)  →  price(定价)  →  mk(组方案 A/F/B/C/D/E)
            →  gate(守门)  →  score(打分)  →  recommended(推荐)  →  actions(动作)  →  quoteText(报价单)
```

## 2. 需求解析（parse）

### 2.1 分段与数量
- 原文按 `，,。；;、换行` 切成片段；`Φ / φ / 直径` 统一为 Φ；多余空白合并。
- 每个片段里找数量：先找 `(\d+(.\d+)?)\s*(吨|t|T)`；没有再找 `(支|根|米|个|件|套|片)`（`个厚` 不算数量）。非吨单位按 §16.1 换算。
- 一个片段里识别出多个规格且只有一个数量：若含「各」则每个规格都取该数量，否则平均分。
- 片段只有数量没有规格：补给上一条尚无数量的规格行；否则暂存。

### 2.2 规格识别规则（按品类）
| 品类 | 识别模式（示例） | 默认材质 | 置信度 |
|---|---|---|---|
| 螺纹钢 / 盘螺 / 线材（高线） | `20 的螺纹`、`螺纹 Φ20`、`Φ12 盘螺`、`16 螺纹` | 螺纹 / 盘螺 HRB400E；线材 HPB300 | 0.95 |
| H 型钢 | `200×200 的 H 型钢`、`H 型钢 300*300` | Q355B | 0.90（注「材质默认 Q355B」） |
| 中板 | `12 个厚的 Q355 中板`、`Q355B 中板 12mm`、`中板 10mm` | 未写材质 → Q235B | 写了材质 0.92；未写 0.75（注「材质未说明」） |
| 热卷 | `5.75 热卷`、`3.0mm 热轧卷` | Q235B | 0.90 |
| 方管 | `方管 100×100×4`、`50×50×2.5 方管` | Q235B | 0.90 / 0.92 |
| 管材（镀锌管 / 焊管 / 无缝管） | `4 寸镀锌管`、`DN100 焊管`、`镀锌管 DN50×3.0`、`Φ108×4 无缝管`、`2 寸管`（未说明镀锌 → 焊管，0.8） | Q235B；无缝 20# | 寸 / DN 未写壁厚 0.93 / 0.90（注「壁厚取常用规格」）；写了壁厚 0.95 |
| 管件（弯头 / 法兰 / 三通） | `DN100 弯头`、`4 寸弯头`、`法兰 DN100` | 碳钢 | 0.92 |
| 角钢 / 槽钢 | `50×5 角钢`、`10# 槽钢` | Q235B | 0.92 / 0.90 |

- 识别出的 key 不在规格目录：置信度压到 ≤ 0.6，注「规格不在目录，需人工核对」。
- 行无数量：置信度压到 ≤ 0.5，注「未识别数量」。
- 任一有效行置信度 < 0.8 → 守门 PARSE_LOW（转人工），见 §7。

### 2.3 交付、付款与信号
| 项 | 规则 |
|---|---|
| 交付方式 | 含「自提 / 来拉 / 自己拉 / 自己来」且不含「送」→ PICKUP；否则 DELIVER。`pickupOk` = 文中出现过自提字样（如「我们自己也可以来拉」），用于允许推荐自提方案 |
| 送货地址 | `送(到|至)? + 2–14 字`，或「老地方 / 原地址」→ 用客户档案地址；区域词（相城 / 园区 / 昆山 / 花桥 …）→ zoneHint |
| 期限 deadlineDays | 今天 / 今日 / 下午 → 0；明天 / 明早 → 1；后天 → 2；这周 / 本周 / 周内 → 5；含「急」→ 1；否则未指定 |
| 付款 | 先发货后付款 / 账期 / 月结 / 照旧 / 挂账 → CREDIT；现款 / 现金 / 款到 / 先款 → CASH；未写 → 按客户档案（有账期则 CREDIT） |
| 信号 flags | 老价格 / 原价 / 上次的价 / 便宜点 / 优惠 → PRICE_CHALLENGE；急 → URGENT；先合作一单 / 看看 / 试试 → TRIAL |

解析结果在工作台可改（规格、数量、期限、付款），改后以人工值为准（置信度记 0.99，备注「人工修正」）。

## 3. 配货：每行的候选货源

对每一询价行（key, 需求 need），依次枚举：

| 顺序 | 来源 | 条件 | 标记 |
|---|---|---|---|
| 1 | 自有库存 OWN | 同 key、可用 > 0；每个仓一个候选 | 库龄 ≥ `agingDays` → AGING |
| 2 | 外部货源（上游 UPSTREAM / 平台 PLATFORM / **市场内档口 MARKET**） | 同 key、可供 > 0；报价超过 `offerStaleH` 小时 → STALE_OFFER | 起订量处理见下；MARKET 距离 0、当天、搬运费 pickFee 计入到岸 |
| 3 | 替代规格（仅自有库存） | `altSpecs[key]` 中的规格有库存 | ALT_SPEC（必须客户确认） |

**起订量（moq）规则**
- need ≥ moq 或无起订量：正常候选。
- need < moq ≤ 可供：仍作候选，但标记 MOQ_STOCK，多买 `rest = moq − need` 吨入库，并把余量持有成本摊到本行：
  `extra = rest × price × creditCostAnnual × 30 / 365 ÷ need`（按 30 天持有计）。
- 可供 < moq：不作候选。

**供货量**：候选量 `q = min(need, 可供)`；q < need → partial（部分供货）。

## 4. 交付方式：每个候选货源 × 五种方式

距离规则：货源与客户同区域 → `km = max(客户档案公里数, 8)`；跨区域 → 查距离矩阵（缺省 60）。  
空驶 deadhead：外部货源专车需从最近的自有仓派车去提货，`deadhead = 最近仓到货源的距离`（同区 6 km）；自有库存为 0。

| 方式 | 条件 | 运费（元/吨） | 装卸 | 到货时长 etaH | 备注 |
|---|---|---|---|---|---|
| a 专车直送 DEDICATED | 总是生成 | `tripFee(km + deadhead, cap) ÷ q`，q > 18 t 用 32 t 车 | handling | leadH + 2 + (km + deadhead)/40 | 外部货源且 q < `transferMinQty` → SMALL_TRANSFER |
| a' 市区配送 CITY | 来源为自有或市场内，客户 ≤ `cityMaxKm`，整单总重 ≤ 10 t | 整单一车：按总重选车（三轮 ≤ 1.5 t 120 + 3/km；4.2 m ≤ 5 t 220 + 5/km；6.8 m ≤ 10 t 320 + 7/km），一趟费 ÷ 整单总重 | handling | leadH + 1 + km/30 | 组方案时按方案内走市区配送的行的总重重新分摊 |
| b 拼车窗口 WINDOW | 存在去客户区域的窗口，余位 ≥ q，发车 ≤ `consolidateMaxDays` 天 | `窗口每吨价 + swing`；自有库存同仓 swing 0、异仓 15；外部货源与起运仓同区 15、不同区不可拼 | handling | 发车时间 + 4 h | 到货 = 窗口标签（明天上午等） |
| c 货源直发 DROPSHIP | 外部货源且 dropship = true | 货源直发运费 dropFee | 0（不过手） | leadH + km/40 + 1 | — |
| d 客户自提 PICKUP | 总是生成 | 0 | handling | leadH + 1 | 定价让利 `pickupDiscount`；客户未提自提时只作备选 |

一趟费（演示价表）：`tripFee(km, cap) = (cap ≥ 30 ? 520 : 380) + km × (cap ≥ 30 ? 9 : 6.5)`。

**同车合并**：组方案时，同一来源的多行都选专车直送 → 合并成一车，一趟费按总吨位分摊，清除 SMALL_TRANSFER，重新定价。

**运费上限**：任一选项折算后运费 > `maxFreightPerTon`（300 元/吨）→ 标 FREIGHT_HEAVY，视为不可行（客户不会接受），方案降权并给出原因。

## 5. 到岸成本

```
landed = base（货源价 / 库存加权成本）
       + freight（运费，§4）
       + handling（装卸，直发为 0）
       + fee（平台货源服务费 platformFee，仅 PLATFORM）
       + credit（账期资金成本 = base × creditCostAnnual × terms / 365，现款为 0）
       + extra（起订量余量持有成本，§3）
```

账期天数 terms：询价写明或客户档案账期；现款为 0。

## 6. 定价

```
target = targetMargin[客户等级] + spec.marginAdd  // A 30 / B 40 / C 55 / N 60；品类加成：镀锌管 / 焊管 / 方管 +60、无缝管 +80、角钢 / 槽钢 +40
if AGING:  target −= agingDiscount              // 老库存让利出清
if PICKUP: target −= pickupDiscount             // 自提让利
p = landed + target
if 有历史价 hist 且 p < hist − 30: p = hist − 10  // 比上次便宜很多时，只微让 10 元，不白送
p = clamp(p, index + band.low (+freight), index + band.high (+freight))   // 市场带；管型材 bandBasis = 'exw'：行情是市场提货价，按「报价 − 运费」比较，配送费另加
p = round10(p)                                   // 取整到 10
margin = p − landed
flags: p − hist > histTolerance → ABOVE_HIST ；margin < floorMargin → BELOW_FLOOR
```

说明：
- **市场带**是硬约束：高于上限会被压到上限（可能导致毛利被压薄甚至为负 → BELOW_FLOOR，表示这条货源 / 方式本身不经济）。
- 规格无指数时，以 `base + 60` 作参考指数。
- 按 个 / 片 结算的管件走 §16.4 的按件定价。
- 人工在报价单上改价：毛利即时重算，低于下限追加原因 BELOW_FLOOR_ADJ 并降级为 NEED_REVIEW。

## 7. 守门（gate）：三级结论与原因码

结论 = 所有命中原因里最高级别：**0 AUTO_SEND 可自动发出 → 1 NEED_REVIEW 需确认后发出 → 2 MANUAL 转人工**。

| 级别 | 原因码 | 触发 | 给销售的「怎么办」 | 可配 |
|---|---|---|---|---|
| 2 | NO_SOURCE | 某行无任何候选货源 | 补充上游询价 / 推荐替代规格 / 只报有货行 | 否 |
| 2 | PARSE_LOW | 某行置信度 < 0.8 | 核对后重新生成 | 否（护栏） |
| 1 | OVERDUE | 客户有逾期应收且本单账期 | 改现款发货或经理审批 | 否（护栏） |
| 1 | NEW_CUSTOMER | 客户等级 N 首单 | 现款 / 预付；核实工商与收货地址 | 否（护栏） |
| 1 | CREDIT_LIMIT | 账期下 已用 + 本单金额 > 信用额度 | 部分现款或缩短账期 | 额度在客户档案 |
| 1 | GRADE | 客户等级不在 `autoSend.grades` | 人工确认后发出 | 是 |
| 1 | AMOUNT | 方案金额 > `autoSend.maxAmount` | 经理确认 | 是 |
| 1 | BELOW_FLOOR | 某行毛利 < `floorMargin` | 换货源 / 自提 / 拼车 / 放弃该行 | 是 |
| 1 | THIN_MARGIN | 最低行毛利 < `autoSend.minMargin`（且无 BELOW_FLOOR） | 确认后发出 | 是 |
| 1 | STALE_OFFER | 用了超过 `offerStaleH` 小时的外部报价 | 刷新上游报价后重算 | 是（护栏：过期报价不可自动发出） |
| 1 | FREIGHT_HEAVY | 某行运费 > `maxFreightPerTon` | 改市区配送 / 拼车 / 自提，或建议客户加量 | 是 |
| 1 | SMALL_TRANSFER | 外部货源 < `transferMinQty` 吨单独专车 | 改拼车 / 直发 / 自提 | 是 |
| 1 | MOQ_STOCK | 为满足起订量需多买入库 | 建议客户加量到起订量，或确认余量可销 | — |
| 1 | ALT_SPEC | 用替代规格 | 报价单注明替代并等待客户确认 | 替代表可配 |
| 1 | ABOVE_HIST | 报价高于客户上次成交价超过 `histTolerance` | 确认按行情上调，或微调到历史价附近 | 是 |
| 1 | PRICE_CHALLENGE | 客户询价里提到老价格 / 优惠 | 人工决定让价幅度（不低于毛利下限） | 否 |
| 1 | DEADLINE | 方案最晚到货晚于客户期限 | 选更快方案或与客户确认交期 | — |
| 1 | PARTIAL | 有行未报价或部分供货 | 报价单注明 | — |

**固定护栏（商家不可放宽）**：置信度 < 0.8 转人工；有逾期不自动放账；新客户首单不自动发出；过期报价不用于自动报价；人工调价低于毛利下限需经理确认。`autoSend` 参数商家只能收紧、不能超过平台上限（建议上限：金额 30 万、最低行毛利 ≥ 15）。

## 8. 方案组合（A–F）

每个方案 = 对每一行按一种「选择器」从候选里挑一个选项（挑不到则该行 missing）。同一来源多行专车自动合并一车（§4）。签名相同的方案去重；E 有缺行则丢弃；D 没有用到替代 / 缺行则丢弃。

| 方案 | 名称 | 行选择器（按顺序尝试） | 适用 |
|---|---|---|---|
| A | 成本最优 · 可按期交付 | 可行¹ ∧ 非替代 ∧ 按期 ∧ 非自提，取**到岸最低** → 可行 ∧ 替代 ∧ 按期 ∧ 非自提 → 非替代 ∧ 按期 ∧ 非自提 → 非替代 ∧ 非自提 | 默认 |
| G | 市区配送 · 整单一车 | 非替代 ∧ 市区配送 ∧ 未过期 ∧ 按期，取毛利最高 → 替代 ∧ 市区配送 ∧ 按期 → 非替代 ∧ 市区配送 | ≤ 10 t 零碎单、管型材 |
| F | 专车直送 · 同车分摊 | 非替代 ∧ 专车 ∧ 报价未过期 ∧ 按期，取毛利最高 | 多行同仓、吨位够一车 |
| B | 最快到货 | 非替代 ∧ 报价未过期 ∧ 非自提，取到货最快 | 急单 |
| C | 客户自提 | 非替代 ∧ 自提 ∧ 可行 → 替代 ∧ 自提 ∧ 可行 → 非替代 ∧ 自提 ∧ 未过期 | 小单、无车、客户提了自提 |
| D | 替代规格 / 部分报价 | 自有 ∧ 可行 ∧ 按期 ∧ 非自提 ∧ 非替代 → 替代 ∧ 可行 ∧ 按期 ∧ 非自提 → 替代 ∧ 按期 | 缺货 |
| E | 全部拼车 | 非替代 ∧ 拼车，取毛利最高 | 不急、有同向车 |

¹ 可行 feasible = 报价未过期 ∧ 非 BELOW_FLOOR ∧ 非 FREIGHT_HEAVY ∧ 非部分供货。  
去重时 G 在 A 之前生成：两者相同则保留「市区配送」标签。D 仅在用到替代规格、或没有任何完整方案时保留；F 部分供货且已有完整方案时丢弃。

方案级汇总：金额 = Σ 报价 × 吨；成本 = Σ 到岸 × 吨；毛利、吨毛利；最晚到货 = 各行 etaH 最大值（全自提显示「随时自提」）；是否按期；是否部分。

## 9. 打分与推荐

```
m    = clamp(吨毛利 / 60, −1, 1)                                  // 毛利，允许为负
d    = 按期 ? 1 : 0.2                                             // 交期
cert = 平均( SRC_CERT[来源] × MODE_CERT[方式] × (替代 ? .6 : 1) × (MOQ_STOCK ? .7 : 1) )
       SRC_CERT: 自有 1 / 市场内 .9 / 上游 .85 / 平台 .75 ；MODE_CERT: 专车 1 / 市区配送 .95 / 自提 .9 / 拼车 .85 / 直发 .8
simp = 来源×方式组合数 ≤1 → 1；=2 → .8；≥3 → .6                     // 简单度（少几个动作）
score = max(0, round((m×.5 + d×.25 + cert×.15 + simp×.1) × 100 × (部分 ? .6 : 1) × (含自提且客户未提 ? .7 : 1) × (≥3 个货源 ? .9 : 1) × (含 FREIGHT_HEAVY ? .6 : 1)))
        + (AUTO_SEND ? +6 : MANUAL ? −15 : 0)
```

**推荐**（按顺序取第一个命中）：
1. 干净² ∧ 不含「客户未提的自提」 ∧ 按期
2. 干净 ∧ 不含「客户未提的自提」
3. 干净 ∧ 按期
4. 干净
5. 非 MANUAL
6. 得分最高者

² 干净 clean = 非 MANUAL ∧ 非部分 ∧ 无 BELOW_FLOOR / FREIGHT_HEAVY 行。

方案列表按得分降序展示，推荐方案标★；销售可选任一方案发出。

## 11. 发出后动作与还价

### 11.1 自动产生的内部动作
| 行的（来源 × 方式） | 动作 |
|---|---|
| 自有 × 专车 | OUTBOUND 出库单 + 派车（> 18 t 用 13 m） |
| 自有 × 市区配送 | OUTBOUND 出库并装车（三轮 / 4.2 m / 6.8 m） |
| 市场内 × 市区配送 | PURCHASE 市场内调货（含搬运费），搬到我方装车位同车发出 |
| 自有 × 拼车 | CONSOLIDATE 加入车次并锁定库存 |
| 外部 × 拼车 | PURCHASE 采购单 + 车次顺路提货 |
| 外部 × 专车 | PURCHASE 采购单 + 专车提货直送 |
| 外部 × 直发 | PURCHASE 采购单（含起订余量），由货源直发 |
| 任意 × 自提 | PICKUP 备货并通知客户（车号 / 提货码）；外部货源先下采购单 |
| 有起订余量（非直发） | STOCK 余量入库并挂牌到平台待售 |
| 每个方案 | FOLLOW 报价有效 `quoteValidH` 小时；未回复 2 小时进入「报价跟单 SOP」 |

报价发出 → RFQ 状态 SENT，生成报价记录，线索下新增 QUOTE_FOLLOW 待办（+2 小时）。客户接受 → 上述动作落成任务，自有库存扣减。过期 → RFQ 退回队列。

### 11.2 还价规则
- 系统允许让价至 **毛利下限**（floorMargin）；仍不够 → 转经理。
- 让价后重发并刷新有效期，记录「让价原因」；客户提到老价格（PRICE_CHALLENGE）的单，由人工决定让价幅度，系统只保证不低于下限。

## 16. 管型材 / 管件扩展（量小而杂、支 / 米 / 个计量、市场内调货、整单一车）

管型材商的询价特征：单均 1–5 t、10–30 行、按**支 / 根 / 米**询按吨结、夹带按**个 / 片**结算的管件、缺货在同一钢材市场内档口互调、一辆小车混装送完。主线不变，以下规则叠加在 §2–§11 之上。

### 16.1 计量与理重换算
规格目录增加：`unit`（吨 / 个 / 片）、`kgPerM` 理重、`stdLen` 定尺（默认 6 m）、`kgPerPiece` 单件重、`dn` / `inch` 口径对照。

| 询价单位 | 结算单位 吨 的规格 | 结算单位 个 / 片 的规格 |
|---|---|---|
| 支 / 根 n | qty = n × kgPerM × stdLen / 1000（保留 3 位），pieces = n | — |
| 米 n | qty = n × kgPerM / 1000，pieces = ⌈n / stdLen⌉ | — |
| 吨 n | qty = n，pieces = round(n × 1000 / (kgPerM × stdLen)) | 置信度降到 0.5，注「按件结算，请给件数」 |
| 个 / 件 / 套 / 片 n | 置信度降到 0.5，注「按吨结算的规格给了件数，请确认」 | qty = pieces = n |

规格不在目录（无理重）但给了支数：qty 为空、置信度 ≤ 0.6 → PARSE_LOW 转人工，并保留支数待人工换算。工作台里「支」和「吨」两个输入框联动，改任一个另一个按理重重算。

**寸 → DN**：1/2 寸 15、3/4 寸 20、1 寸 25、1.2 寸 32、1.5 寸 40、2 寸 50、2.5 寸 65、3 寸 80、4 寸 100、5 寸 125、6 寸 150。未写壁厚取目录中该口径的常用壁厚（如 4 寸 × 3.75）；写了壁厚但目录没有 → 生成 `品名|Q235B|DN×壁厚` 并标「不在目录」。

### 16.2 货源：市场内档口（MARKET）
- 与自有库存同区域（同一钢材市场），距离 0、备货 1 小时、不可直发；到岸成本在货源价外加 `pickFee` 搬运费（15 元/吨），账期资金照算。
- 可走：专车（空驶 0）、市区配送、拼车（顺路 +5）、自提（客户到档口提）。不受 SMALL_TRANSFER 约束。
- 来源：销售投喂档口报价（微信 / 口头），或平台「同市场商家」挂牌自动进入；时效按 `offerStaleH`。

### 16.3 交付：市区配送（CITY，整单一车）
- 条件：来源为自有或市场内，客户距离 ≤ `cityMaxKm`，整单总重 ≤ 10 t。
- 车型按**整单总重**选：三轮 / 小厢货 ≤ 1.5 t（120 + 3/km）、4.2 m ≤ 5 t（220 + 5/km）、6.8 m ≤ 10 t（320 + 7/km）。
- 每行运费 = 一趟费 ÷ 方案内走市区配送的行的总重 × 该行每单位重量；组方案时按实际入车的行重新分摊。
- 到货 = 备货 + 1 h + km/30。
- 方案 G「市区配送 · 整单一车」专门承载这种交付；A 在按到岸最低挑选时也会自然选到它。

### 16.4 按件定价（管件）
```
参考价 idx = spec.index（无则 base × 1.25）
p = landed + base × pieceMarginRate            // 18%；自提 −3 个百分点
if hist 且 p < hist: p = hist                   // 管件不主动比上次便宜
p = clamp(p, idx × (1 − 8%), idx × (1 + 15%))
p = round to 0.5
marginRate = margin / landed
BELOW_FLOOR: margin < base × pieceFloorRate（6%）；ABOVE_HIST: p > hist × 1.1
THIN_MARGIN（管件）: 最低行毛利率 < autoSendMinMarginRate（8%）
```
管件行的运费 / 装卸 / 平台费 = 吨价 × 单件重（kg / 1000），通常不足 1 元；不参与 AGING 让利。

### 16.5 管材定价差异
- 目标毛利 = 等级目标 + 品类加成 `marginAdd`（镀锌管 / 焊管 / 方管 +60、无缝管 +80、角钢 / 槽钢 +40）。
- 市场带 `band` 默认 −40 / +60，`bandBasis = 'exw'`：指数是市场提货价，带与「报价 − 运费」比较，配送费另加；否则 2 t 送 30 km（189 元/吨）必然被压到负毛利。
- 运费上限 `maxFreightPerTon` 300：9.6 m 平板送 0.7 t 方管（837 元/吨）这类选项直接判不可行。

### 16.6 守门与打分差异
- FREIGHT_HEAVY（§7）；管件行 THIN_MARGIN / BELOW_FLOOR 按毛利率；≥ 3 个货源的方案 ×0.9（多档口调货的操作成本）；含 FREIGHT_HEAVY 行 ×0.6。
- 其余（信用 / 逾期 / 新客户 / 金额 / 过期 / 替代 / 期限 / 部分）与建材相同。
