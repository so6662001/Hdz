### 2.1 询价队列（左）
- 卡片：渠道图标（微信 / 语音 / 电话 / 企微 / 平台 / 手工）、联系人 · 客户名、状态标签（待报价 橙 / 已报价 绿 / 转人工 红 / 已成交 / 已过期）、原文两行截断、时间 · 渠道 · 客户等级 · 归属销售。
- 排序：待报价在前，其次按时间倒序。点击 → 中栏重算并更新 URL `?tab=work&rfq=`。
- 新询价：粘贴原文 + 选客户 → 建 RFQ（渠道 手工）→ 立即解析生成方案；示例 chips 用于演示。

### 2.2 客户卡（中 ①）
等级块颜色：A 橙、B 蓝、C 黄、N 灰。信用条 > 85% 变橙。历史价直接列在卡内（销售谈价最常看的两个数：上次成交价、市场指数）。右侧显示询价原文和解析出的信号标签（提到老价格 / 急单 / 试单）。

### 2.3 AI 识别结果（中 ②）
- 表格可编辑：规格下拉（目录全量，不在目录的保留原文项）、数量、置信度标签（< 80% 黄）、识别依据「原文片段」+ 备注（材质默认 / 未识别数量 / 理重换算式 / 人工修正）。
- 数量单元格按规格结算单位变化：按吨的管型材显示 **「支」与「t」两个输入框**（改任一个另一个按理重 × 定尺重算，下方小字显示 kg/m × 定尺）；管件显示「个 / 片」；建材显示「t」。
- 改规格 / 数量 / 删行 / 加行 / 改期限 / 改付款 → 立即重新生成方案（覆盖值进 `over`，不改原文）。
- 解析为自提时显示「客户自提」；仅提到可自提时显示「送货（客户可自提）」。

### 2.4 接单方案卡（中 ③）
```
┌ [A] 成本最优 · 可按期交付   [推荐]   [需确认后发出]           得分 76 ┐
│ 规格 | 吨 | 货源 · 方式 | 到岸 | 报价 | 毛利/t | 到货                      │
│ 螺纹钢 HRB400E Φ20 | 8 | [自有] 相城主仓 · 拼车 TW1 | 3784 | 3820 (上次 3790) | 36 | 明天上午 │
│ 盘螺 HRB400E Φ12  | 5 | [平台] 苏州某钢贸 · 货源直发 | 3927 | 3970 (上次 3905) | 43 | 今天  │
│ 合计 13 t · 金额 ¥50,410 · 毛利 ¥507 (39/t) · 最晚到货 明天                 │
│ ⚠ 盘螺 报价 3970 高于客户上次成交 3905 → 确认是否按行情上调…                 │
│ ⚠ 客户在询价中提到老价格 / 优惠 → 人工决定让价幅度（不低于毛利下限）           │
│ 每行取到岸成本最低、满足交期、无硬伤…                         [选用此方案]  │
└──────────────────────────────────────────────────────────────────────────┘
```
- 单列排列，按得分降序；推荐卡蓝边 + 「推荐」标签；选中卡橙色描边。
- 守门结论色块：可自动发出 绿 / 需确认后发出 黄 / 转人工 红；原因最多显示 4 条，其余折叠「共 n 条」；全通过显示「✓ 全部守门规则通过」。
- 毛利颜色：< 下限 红、< 自动发出最低 黄、其余绿；负毛利方案合计也标红。
- 行内标记文字：老库存 / 起订余量入库 / 报价过期 / 零散调货 / 替代规格 / 运费超限（替代行在规格下方黄字写「替代 原规格」）；无货源行整行灰字「— 无可用货源」。
- 数量列按单位显示「30 支（0.671 t）」「10 个」「8 t」；货源标签：自有 绿、平台 蓝、**市场内调货 橙**、上游 灰；方式含「市区配送」；管件行毛利显示「6.6 (23.2%)」并按毛利率着色。

### 2.5 报价单面板（中 ④）
- **左：客户看到的**。文本域预填引擎生成的报价单（联系人 / 条目 / 合计 / 送达地 / 有效期 / 「需要我现在锁货吗？」），可直接改。下方每行一个价格微调框（步长 10）：改价即时重算该行与方案毛利，低于下限追加原因并降级为「需确认」。
- 按钮按守门结论切换：AUTO_SEND → 蓝色「发送报价」；NEED_REVIEW → 橙色「确认并发送」；MANUAL → 禁用「需人工处理后才能发送」。另有「转人工 / 经理」（弹窗：原因下拉 + 备注 → RFQ 转人工、经理收通知）、「复制文本」、「在会话中发送」（有线索时）。
- **右：内部视图**。每行一块「到岸成本拆解」：货源价 / 运费 / 装卸 / 平台服务费 / 账期资金（n 天）/ 起订余量持有 → 到岸 → 报价 → 毛利，条形图按报价为满格；下方一行小字：定价备注（压到带上限 / 按历史价微让 / 老库存让利）+ 市场指数与带宽。再下方「发出后自动产生的动作」列表：出库 / 拼车 / 采购 / 自提 / 入库 / 跟单 标签 + 文本。
- 发送后：生成报价记录（含方案、守门结论、行、动作、文本、有效期）、RFQ → 已报价、线索新增 QUOTE_FOLLOW 待办（+2 小时）、看板通知；页面切到「报价记录」。

### 2.6 右栏
市场参考（所询规格 + 替代规格的指数与上次成交价）、自有库存（含替代规格；老库存标签；管材同时显示「≈ n 支」）、外部货源（平台 / 上游 / **市场内** 标签、起订、可否直发或搬运费、报价时间，过期红字；「刷新上游报价」演示按钮）、**市区配送**（三轮 / 4.2 m / 6.8 m 到客户的一趟价、整单吨位对应车型、距离与运费上限说明）、拼车窗口（去客户区域方向的车次；无车时提示「零碎单建议自提 / 直发 / 等拼单」）。右栏是销售在不信任系统时「自己核对一眼」的地方，所有数都和中栏同源。

## 3. Tab「规则参数」

```
接单方案引擎 · 规则参数                               [恢复默认] [保存并重算]
定价：目标毛利 A/B/C/N · 毛利下限 · 市场带下限/上限 · 高于历史价提示阈值 · 自提让利 · 老库存天数/让利 · 账期资金成本（年化）
自动发出（守门）：允许等级 · 金额上限 · 最低行毛利 · 报价有效期 · 上游报价过期（小时）
配货与物流：零散调货最小吨位 · 可接受拼车等待（天） · 平台货源服务费
管型材 / 管件：市区配送最远公里 · 单行运费上限 · 管件目标毛利率 / 下限 / 自动发出最低毛利率 · 管件参考价带（比例）；说明：管材市场带按提货价比较、配送费另加，品类加成与理重在规格目录维护
替代规格（需客户确认）：原规格 → 替代规格列表（只读展示，二期可编辑）
ⓘ 固定护栏（不可配）：置信度 < 80% 转人工；逾期不自动放账；新客户首单不自动发出；过期报价不用于自动报价；人工调价低于下限需经理确认。
```
- 三列表单，每项有一句提示语（直接写规则含义，如「低于此值的行不允许自动发出」）。
- 保存 → 写入 config → 待报价询价全部重算 → 回到「询价与报价」。权限：管理员 / 老板可改；销售只读。
- 二期：参数修改留痕（谁、何时、从 → 到）；平台上限校验（§02 §7 护栏）。

## 4. Tab「报价记录」

表格：报价（编号 · 时间 · 销售 · 方案）| 客户 | 内容（每行 规格 吨 × 价 · 方式 · 到货）| 金额 / 毛利（负毛利红）| 发出方式（自动 / 确认 / 人工 色块）| 状态（已报价 / 已成交 / 已过期 / 未成交 + 备注）| 操作。

操作（已报价状态）：
- **模拟客户接受**：状态 → 已成交；自有库存按行扣减；生成「出库单 / 拼车任务 / 采购单 / 自提通知 / 入库单」备注；看板通知「成交」。
- **模拟还价**：弹窗显示还价规则（最多让到毛利下限，否则转经理），输入让价元/吨 → 重发并更新备注；低于下限时提示已转经理。
- **过期**：状态 → 已过期；RFQ 退回队列；备注「跟单 SOP 已提醒销售电话确认」。
- 其他状态：查看 → 抽屉显示发出的文本与内部动作。
