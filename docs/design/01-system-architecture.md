# 货袋子平台 — 分站管理与广告管理模块 系统架构设计

> 版本：v1.0 | 日期：2026-02-23

---

## 一、项目背景与目标

货袋子平台（huodaizi.com）现有首页（/fullscreen）作为平台展示入口。本次需求在此基础上新增以下能力：

1. **分站体系**：根据用户所在城市自动匹配并展示对应分站首页
2. **广告体系**：分站首页由多种广告版块组成，不同版块对应不同价位，由运营后台统一管理
3. **后台管理**：提供分站管理、广告管理两个后台模块，以可嵌入方式集成到现有运营系统
4. **首页改版**：现有 /fullscreen 页面转型为平台介绍页

## 三、模块划分

### 3.1 模块列表

| 模块名称 | 包路径 | 职责 |
|---------|--------|------|
| hdz-sub-station | com.hdz.substation | 分站管理、城市与分站绑定、分站配置 |
| hdz-advertisement | com.hdz.advertisement | 广告版块管理、广告位管理、广告投放与审核 |
| hdz-common | com.hdz.common | IP 定位、文件上传、通用工具、权限对接 |

### 3.2 模块间关系

```
hdz-common（基础模块）
    ▲           ▲
    │           │
hdz-sub-station  hdz-advertisement
    ▲
    │
hdz-advertisement（广告依赖分站，广告按分站投放）
```

### 3.3 与现有系统集成方式

两个管理模块以 **Maven 子模块 / 独立 JAR 包** 的形式嵌入现有系统：

1. **后端集成**：作为 Spring Boot Starter 或 Maven 依赖引入，自动注册 Controller、Service、Mapper
2. **前端集成**：管理页面以**独立前端路由模块**方式嵌入，支持 iframe 嵌入或微前端方式加载
3. **权限集成**：对接现有系统的权限体系，通过 SPI 接口获取当前登录用户信息与权限列表
4. **菜单集成**：模块启动时自动向系统菜单注册管理入口

## 四、技术选型

| 层次 | 技术 | 说明 |
|------|------|------|
| 后端框架 | Spring Boot 2.7+ / 3.x | 主框架 |
| ORM | MyBatis-Plus | 数据访问 |
| 数据库 | MySQL 8.0 | 主数据存储 |
| 缓存 | Redis | 热数据缓存（分站配置、广告数据） |
| IP 定位 | ip2region / 高德 API | 用户城市定位 |
| 文件存储 | OSS / MinIO | 广告素材存储 |
| 前端框架 | Vue 3 + Element Plus | 后台管理页面 |
| 前端（C端） | 响应式 HTML/CSS/JS | 分站首页、平台介绍页 |
| API 风格 | RESTful | 统一接口规范 |
| 接口文档 | Swagger / Knife4j | 接口文档自动生成 |

## 五、核心流程

### 5.1 用户访问分站首页流程

```
用户访问 huodaizi.com
       │
       ▼
  Nginx / 前端判断
  是否已有城市 Cookie?
       │
   ┌───┴───┐
   │ 是    │ 否
   ▼       ▼
跳转到    调用 IP 定位接口
对应分站   获取用户城市
   │       │
   │       ▼
   │    城市是否有对应分站？
   │       │
   │   ┌───┴───┐
   │   │ 是    │ 否
   │   ▼       ▼
   │  跳转到   展示城市选择页
   │  对应分站  或默认分站
   │   │       │
   └───┴───────┘
       │
       ▼
  加载分站首页
  请求该分站下的广告数据
       │
       ▼
  按版块渲染广告内容
```

### 5.2 广告投放流程

```
运营人员登录后台
       │
       ▼
  选择目标分站
       │
       ▼
  选择广告版块（Banner / 推荐位 / 列表区等）
       │
       ▼
  创建广告（上传素材、填写链接、选择时段）
       │
       ▼
  设置广告价格 & 排序权重
       │
       ▼
  提交审核 → 审核通过 → 上线投放
       │
       ▼
  广告数据写入 DB + 同步到 Redis 缓存
       │
       ▼
  用户端实时展示
```

## 七、安全设计

| 安全维度 | 措施 |
|---------|------|
| 接口鉴权 | 后台接口统一走现有系统的 Token/Session 鉴权 |
| 数据隔离 | 广告数据按分站隔离，运营人员按权限查看对应分站 |
| 防刷保护 | C 端广告接口加限流（令牌桶），防止恶意爬取 |
| XSS 防护 | 广告内容入库时过滤 HTML 标签，输出时转义 |
| 素材审核 | 广告素材上传后经审核流程方可上线 |
| 操作日志 | 所有后台操作记录审计日志 |
