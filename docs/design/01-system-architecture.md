# 货袋子平台 — 分站管理与广告管理模块 系统架构设计

> 版本：v2.0 | 日期：2026-02-23  
> 更新说明：新增招商/广告需求登记体系、企业微信通知、广告赠送/收费模式、用户分站记忆、广告跳转链接类型等

---

## 一、项目背景与目标

货袋子平台（huodaizi.com）现有首页（/fullscreen）作为平台展示入口。本次需求在此基础上新增以下能力：

1. **分站体系**：根据用户所在城市自动匹配并展示对应分站首页；已登录用户自动记忆上次访问的分站
2. **广告体系**：分站首页由多种广告版块组成，不同版块对应不同价位，支持赠送与收费两种模式，到期后可调整位置，由运营后台统一管理
3. **招商与广告需求登记**：首页及分站首页提供招商入口与广告需求登记入口，客户提交后即时推送企业微信通知到指定责任人，运营后台可查看并填写跟进记录（数据不可删除和修改，仅可追加跟进）
4. **后台管理**：提供分站管理、广告管理、招商/需求登记管理三大后台模块，以可嵌入方式集成到现有运营系统
5. **首页改版**：现有 /fullscreen 页面转型为平台介绍页，含招商入口与广告需求登记入口

## 三、模块划分

### 3.1 模块列表

| 模块名称 | 包路径 | 职责 |
|---------|--------|------|
| hdz-sub-station | com.hdz.substation | 分站管理、城市与分站绑定、分站配置、用户分站记忆 |
| hdz-advertisement | com.hdz.advertisement | 广告版块管理、广告位管理、广告投放与审核、赠送/收费管理、到期位置调整、广告跳转链接 |
| hdz-leads | com.hdz.leads | 招商登记管理、广告需求登记管理、跟进记录管理、企业微信即时通知 |
| hdz-common | com.hdz.common | IP 定位、文件上传、通用工具、权限对接、企业微信 SDK 封装 |

### 3.2 模块间关系

```
hdz-common（基础模块，含企微 SDK）
    ▲           ▲            ▲
    │           │            │
hdz-sub-station  hdz-advertisement  hdz-leads
    ▲                                  │
    │                                  │（登记可关联分站）
    └──────────────────────────────────┘
```

### 3.3 与现有系统集成方式

三个管理模块以 **Maven 子模块 / 独立 JAR 包** 的形式嵌入现有系统：

1. **后端集成**：作为 Spring Boot Starter 或 Maven 依赖引入，自动注册 Controller、Service、Mapper
2. **前端集成**：管理页面以**独立前端路由模块**方式嵌入，支持 iframe 嵌入或微前端方式加载
3. **权限集成**：对接现有系统的权限体系，通过 SPI 接口获取当前登录用户信息与权限列表
4. **菜单集成**：模块启动时自动向系统菜单注册管理入口
5. **消息集成**：通过企业微信 Webhook / 应用消息 API 实现即时通知

## 四、技术选型

| 层次 | 技术 | 说明 |
|------|------|------|
| 后端框架 | Spring Boot 2.7+ / 3.x | 主框架 |
| ORM | MyBatis-Plus | 数据访问 |
| 数据库 | MySQL 8.0 | 主数据存储 |
| 缓存 | Redis | 热数据缓存（分站配置、广告数据、用户分站记忆） |

| 前端（C端） | 响应式 HTML/CSS/JS | 分站首页、平台介绍页 |
| API 风格 | RESTful | 统一接口规范 |
| 接口文档 | Swagger / Knife4j | 接口文档自动生成 |

## 六、企业微信消息通知设计

### 6.1 通知触发场景

| 触发事件 | 通知内容 | 通知目标 |
|---------|---------|---------|
| 新招商登记提交 | 企业名称、联系人、电话、合作意向 | 招商责任人（企微用户） |
| 新广告需求登记提交 | 企业名称、联系人、电话、意向版块、预算 | 广告销售责任人（企微用户） |
| 广告即将到期（提前 3 天） | 广告标题、到期时间、所属分站 | 广告运营责任人（企微用户） |
| 广告已到期 | 广告标题、是否允许位置调整 | 广告运营责任人（企微用户） |

### 6.2 通知方式

| 方式 | 适用场景 | 说明 |
|------|---------|------|
| Webhook 机器人 | 群通知 | 推送到指定企微群，所有群成员可见 |
| 应用消息 | 精准推送 | 推送到指定企微用户，一对一通知 |

### 6.3 消息模板示例

```
【新招商登记通知】
━━━━━━━━━━━━━━━━
企业名称：XX科技有限公司
联系人：张先生
联系电话：13800138000
所在城市：深圳
合作意向：入驻深圳站
登记时间：2026-03-15 14:30:22
━━━━━━━━━━━━━━━━
请及时跟进处理 →
```

### 6.4 配置管理

后台可配置：
- 企业微信 Webhook URL
- 企业微信应用 CorpId / AgentId / Secret
- 各类通知的接收人列表（企微用户 ID）
- 通知开关（可按类型开启/关闭）
- 通知静默时段（如凌晨不推送，改为次日上午汇总推送）

## 八、安全设计

| 安全维度 | 措施 |
|---------|------|
| 接口鉴权 | 后台接口统一走现有系统的 Token/Session 鉴权 |
| 数据隔离 | 广告数据按分站隔离，运营人员按权限查看对应分站 |
| 防刷保护 | C 端广告接口加限流（令牌桶），防止恶意爬取 |
| 表单防刷 | 招商/需求登记表单加图形验证码 + IP 频率限制（同 IP 每小时最多 5 次） |
| XSS 防护 | 广告内容入库时过滤 HTML 标签，输出时转义 |
| 素材审核 | 广告素材上传后经审核流程方可上线 |
| 操作日志 | 所有后台操作记录审计日志 |
| 数据保护 | 招商/需求登记数据禁止物理删除和修改，仅允许追加跟进记录和更新处理状态 |
| 企微安全 | 企业微信 API 密钥加密存储，Token 自动刷新 |
