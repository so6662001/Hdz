# 货袋子平台 — 微信小程序设计方案

> 版本：v2.0 | 日期：2026-02-23  
> 更新说明：新增"圈子"模块作为小程序端广告内容的核心展示形态，将传统广告版块社交化呈现

---

## 一、为什么要做小程序

### 1.1 PC 端 vs 小程序端的定位差异

| 维度 | PC 端（已确认） | 微信小程序 |
|------|----------------|-----------|
| 核心用户 | 运营人员（后台）、企业主（浏览） | 普通用户（高频浏览）、企业主（快速登记） |
| 使用场景 | 办公桌前、深度浏览 | 移动碎片化、随时随地 |
| 流量入口 | 搜索引擎、直接访问 | 微信搜索、朋友圈分享、微信群转发、公众号引流、扫码 |
| **广告展示形态** | **版块化**（Banner、推荐位、列表等） | **圈子化**（社交 Feed 流，本地商圈社区） |
| 核心价值 | 完整管理、数据分析 | 快速触达用户、社交裂变、降低使用门槛 |
| 登录方式 | 账号密码 | 微信一键授权（零门槛） |
| 定位方式 | IP 定位 | 微信定位 API（GPS 级精准） |

### 1.2 小程序的核心优势

1. **免安装、即用即走**：用户无需下载，微信内直达
2. **微信社交裂变**：圈子内容可一键分享到微信群/朋友圈，带来免费流量
3. **精准定位**：微信 `wx.getLocation` 精准到街道级别，远超 IP 定位
4. **微信登录**：一键授权获取用户身份，零注册门槛
5. **订阅消息**：可向用户推送招商/广告相关通知
6. **扫码能力**：线下物料扫码直达分站或圈子内容
7. **微信支付**：未来收费广告可直接通过微信支付完成

## 二、"圈子"核心设计理念

### 2.1 什么是圈子

**圈子 = 本地商圈社区**。每个分站拥有自己的"圈子"，将原本 PC 端的广告版块内容转化为社交化 Feed 流形态，让企业广告不再是冷冰冰的横幅，而是变成本地商圈中的**动态、资讯和推荐**。

### 2.2 圈子 vs 传统广告版块

| 维度 | PC 端广告版块 | 小程序"圈子" |
|------|-------------|-------------|
| 展示形态 | Banner、推荐位、列表 — 版块化、静态 | Feed 流、动态卡片 — 社交化、沉浸式 |
| 内容感知 | 用户明确知道是"广告" | 用户感觉是在"逛本地商圈"，广告融入内容 |
| 排列方式 | 按广告位固定排列 | 按时间线/热度/分类 灵活排列 |
| 互动性 | 仅点击跳转 | 点赞、评论、分享、收藏 |
| 内容丰富度 | 单图+标题+链接 | 多图、视频、图文、活动信息 |
| 社交属性 | 无 | 可分享、可评论、有热度排名 |
| 更新频率 | 按投放周期更新 | 企业可持续发布动态，保持活跃度 |
| 用户黏性 | 低（看完即走） | 高（形成刷圈子的习惯） |

### 2.3 圈子的业务价值

1. **提升广告价值**：社交化呈现让广告更自然，点击率更高
2. **增强用户黏性**：用户养成"刷圈子"习惯，日活和留存提升
3. **丰富广告形式**：除了传统图片广告，企业可发布活动、优惠、招聘等多种动态
4. **社交裂变**：圈子内容天然适合分享到微信群和朋友圈
5. **差异化竞争**：与 PC 端形成互补，小程序不是 PC 的缩小版，而是完全不同的产品形态

## 三、整体架构

### 3.1 技术选型

| 层次 | 技术 | 说明 |
|------|------|------|
| 小程序框架 | uni-app（推荐）或原生微信小程序 | uni-app 可同时输出微信/支付宝/H5 |
| UI 组件库 | uView UI / Vant Weapp | 移动端组件成熟 |
| 状态管理 | Pinia（uni-app）/ globalData | 轻量状态管理 |
| 网络请求 | uni.request / wx.request 封装 | 统一拦截、Token 注入 |
| 地图/定位 | 微信定位 API + 腾讯地图 SDK | 城市级定位 |
| 后端 API | 复用现有 Java 后端 + 圈子新增接口 | RESTful |

## 四、小程序页面结构与导航

### 4.1 页面结构总览

```
TabBar（底部导航，4个Tab）
├── 首页 Tab (/pages/home/index)
│   ├── 自动定位 → 分站首页
│   ├── Banner 轮播广告
│   ├── 推荐企业（精选）
│   └── 快捷入口：招商入驻 / 广告投放 / 进入圈子
│
├── 🆕 圈子 Tab (/pages/circle/index)  ← 核心页面
│   ├── 分类标签（全部/餐饮/科技/教育/建材/...）
│   ├── 排序切换（推荐/最新/热门）
│   ├── Feed 流动态卡片列表
│   └── 互动（点赞/评论/分享/收藏）
│
├── 分站 Tab (/pages/city/index)
│   └── 城市选择 → 切换分站和圈子
│
└── 我的 Tab (/pages/mine/index)
    ├── 微信登录
    ├── 我的收藏 / 我的点赞
    ├── 我的登记记录
    └── 联系客服

子页面（非 Tab 页）
├── /pages/circle/detail         圈子动态详情（评论互动）
├── /pages/circle/enterprise     企业主页（该企业所有动态）
├── /pages/ad/detail             广告详情页（付费广告）
├── /pages/inquiry/submit        招商登记提交页
├── /pages/demand/submit         广告需求登记提交页
├── /pages/inquiry/list          我的招商登记记录
├── /pages/demand/list           我的广告需求记录
└── /pages/webview/index         WebView（打开外链）
```

### 4.2 底部 TabBar 设计

```
┌──────────────────────────────────────────────────────────┐
│                                                          │
│                    页面内容区域                            │
│                                                          │
├──────────────┬──────────────┬──────────────┬─────────────┤
│     🏠       │     🔥       │     🏙️       │     👤      │
│    首页      │    圈子       │    分站       │    我的     │
└──────────────┴──────────────┴──────────────┴─────────────┘
```

- **首页**：分站门面，Banner + 精选推荐 + 快捷入口（轻量、引导性）
- **圈子**：核心内容消费页面，社交 Feed 流，用户 60%+ 时间在此
- **分站**：城市选择、分站切换
- **我的**：个人中心、收藏/点赞、登记记录

### 5.2 圈子动态的 4 种内容类型

| 类型 | 英文代码 | 展示形态 | 来源 |
|------|---------|---------|------|
| 图文动态 | IMAGE_TEXT | 文字 + 1~9 张图片（九宫格） | 后台发布 / 从广告内容同步 |
| 视频动态 | VIDEO | 文字 + 视频（封面+播放） | 后台发布 |
| 活动/优惠 | ACTIVITY | 活动卡片（醒目样式，含时间/地址/电话） | 后台发布 |
| 付费推广 | PROMOTED | 同上述任意样式，但带 "AD" 角标，排序靠前 | 从 hdz_ad_content 同步 |

### 8.7 与 PC 端广告数据的关系

```
hdz_ad_content（PC端广告内容表）
        │
        │  付费广告自动同步
        │  (ad_content_id 关联)
        ▼
hdz_circle_post（圈子动态表）
        │
        ├── hdz_circle_like（点赞）
        ├── hdz_circle_comment（评论）
        ├── hdz_circle_favorite（收藏）
        └── hdz_circle_category（分类）
```

- **付费广告同步**：PC 端 `hdz_ad_content` 中审核通过的广告自动同步为圈子动态（`post_type=PROMOTED`），在圈子 Feed 中带 "AD" 标识展示
- **免费动态**：运营后台可独立发布圈子动态（`post_type=IMAGE_TEXT/VIDEO/ACTIVITY`），不依赖广告系统
- **后台统一管理**：圈子动态在运营后台以"圈子管理"菜单统一管理

## 十二、PC 端与小程序端完整差异对照

| 功能 | PC 端 | 小程序端 | 差异说明 |
|------|------|---------|---------|
| 平台介绍页 | 有（/fullscreen） | 无 | 小程序直达分站首页 |
| **广告展示形态** | **版块化**（5种广告版块） | **圈子化**（社交Feed流） | **核心差异：完全不同的产品形态** |
| Banner 广告 | 有 | 有（首页保留） | Banner 作为高价值广告位在首页保留 |
| 推荐企业 | 4 列网格 | 2 列网格（首页保留） | 首页轻量展示 |
| 列表广告 | 版块列表 | 圈子 Feed 流 | 社交化呈现 |
| 侧边栏广告 | 有 | 无 | 移动端无侧边栏 |
| 弹窗广告 | 有 | 无 | 小程序体验差 |
| **圈子** | **无** | **有（核心功能）** | **小程序独有** |
| **点赞/评论/收藏** | **无** | **有** | **社交互动** |
| **企业主页** | **无** | **有** | **企业独立展示空间** |
| 广告点击 | 直接跳转外链 | 动态详情页 → 跳转 | 中间页增加信息和互动 |
| 分享能力 | URL 复制 | 微信分享/海报 + 圈子动态分享 | 圈子内容天然适合分享 |
| 登录 | 账号密码 | 微信一键授权 | 零门槛 |
| 手机号 | 手动输入 | 微信一键获取 | 提高转化 |
| 定位 | IP 定位 | GPS 精准定位 | 精度差距大 |
| 客服 | 展示电话 | 微信客服会话 | 体验更好 |
| 通知 | 企微（运营） | 订阅消息（用户）+ 企微（运营） | 互补 |
| 后台管理 | 有 | 无 | 管理仅 PC 端 |

## 十三、性能优化

### 13.1 小程序包体积

| 策略 | 说明 |
|------|------|
| 分包加载 | 主包：首页+圈子（核心体验）；子包：城市/登记/详情/设置 |
| 图片 CDN | 所有图片走 CDN，小程序包内不放图片 |
| 按需引入 | 组件库按需引入 |

### 13.2 圈子 Feed 性能

| 策略 | 说明 |
|------|------|
| 虚拟列表 | Feed 超过 30 条时使用虚拟列表 |
| 图片懒加载 | 进入视窗才加载图片 |
| 视频懒加载 | 滑到视频卡片时才加载视频组件 |
| 分页加载 | 每次 10 条，触底加载更多 |
| 本地缓存 | 首屏数据缓存到 Storage，先展示缓存再刷新 |
| 点赞乐观更新 | 点赞操作本地立即响应，异步提交服务端 |
