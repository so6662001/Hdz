> 日期：2026-02-23

---

## 需求概述

在现有货袋子平台首页（/fullscreen）基础上，新增以下功能：

1. **分站管理**：根据用户所在城市自动匹配对应分站，展示本地化内容
2. **广告管理**：分站首页以企业广告为主，不同版块有不同价位，后台统一管理
3. **首页改版**：原首页转型为平台介绍页
4. **模块化集成**：分站管理和广告管理作为独立模块嵌入现有系统

## 核心页面预览

### C 端用户页面

- **平台介绍页**（/fullscreen）：Hero 区域 + 平台优势 + 热门分站 + 数据统计 + 广告合作 + 页脚
- **分站首页**（/s/{stationCode}）：5 大广告版块 —— 顶部 Banner、推荐企业、列表广告、侧边栏、弹窗广告
- **城市选择页**（/s/select-city）：搜索 + 定位 + 热门城市 + 字母索引

### B 端管理页面

- **分站管理**：列表 → 新增/编辑 → 城市绑定 → 配置管理
- **广告管理**：版块管理 → 广告位管理 → 广告内容管理 → 审核 → 定价 → 订单 → 数据统计

## 技术栈

| 层次 | 技术 |
|------|------|
| 后端 | Java + Spring Boot + MyBatis-Plus + MySQL + Redis |
| 前端（管理端） | Vue 3 + Element Plus |
| 前端（C 端） | 响应式 HTML/CSS/JS |
| IP 定位 | ip2region / 高德 API |
| 文件存储 | OSS / MinIO |
| 图表 | ECharts |

## 设计风格

- **简洁**：去除多余装饰，内容优先
- **主色调**：#1890FF（科技蓝）
- **辅助色**：#52C41A（成功绿）、#FAAD14（警告黄）、#FF4D4F（危险红）
- **圆角**：按钮 4px，卡片 8px，弹窗 12px
- **字体**：标题 Semi Bold，正文 Regular，数据 Bold
