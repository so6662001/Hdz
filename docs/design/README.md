## 需求概述

在现有货袋子平台首页（/fullscreen）基础上，新增以下功能：

1. **分站管理**：根据用户所在城市自动匹配对应分站；已登录用户自动记忆上次分站
2. **广告管理**：分站首页以企业广告为主，不同版块有不同价位，支持赠送（免费）与收费两种模式，到期后可配置位置调整，后台统一管理
3. **广告跳转**：广告点击可打开商家首页（PC+移动端）、公司官网或自定义链接
4. **招商入驻入口**：首页和分站首页提供招商入驻登记入口
5. **广告需求登记入口**：首页和分站首页提供广告投放需求登记入口
6. **企业微信即时通知**：客户登记后立即推送消息到企微指定责任人
7. **跟进记录管理**：运营后台查看登记数据（不可删除/修改），可追加多条跟进记录（不可删除/修改）
8. **首页改版**：原首页转型为平台介绍页，含招商入口和广告需求登记入口
9. **模块化集成**：所有模块作为独立 JAR 嵌入现有系统

## 核心页面预览

### C 端用户页面

- **平台介绍页**（/fullscreen）：Hero 区域 + 平台优势 + 热门分站 + **招商入驻区块** + **广告需求登记入口** + 广告合作价格方案
- **分站首页**（/s/{stationCode}）：**快捷入口栏（招商/广告需求）** + 5 大广告版块 + 底部招商 CTA
- **招商登记弹窗**：企业信息 + 联系方式 + 合作意向 + 验证码
- **广告需求登记弹窗**：企业信息 + 意向版块 + 预算 + 验证码
- **城市选择页**（/s/select-city）

### B 端管理页面

- **分站管理**：列表 → 新增/编辑 → 城市绑定 → 配置管理
- **广告管理**：版块管理 → 广告位 → 广告内容（**含赠送/收费标识、位置调整**） → 审核 → 定价 → 订单 → 统计
- **招商/需求管理**：登记列表（不可删改）→ 详情 + 跟进记录时间线（仅可追加）
- **系统设置**：企微通知配置 → 通知测试
