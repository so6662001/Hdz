#### 广告版块类型与布局规格

| 版块类型 | 英文代码 | 展示位置 | 建议尺寸 | 最大广告数 | 价位定位 |
|---------|---------|---------|---------|-----------|---------|
| 顶部轮播 Banner | BANNER | 页面最顶部，全宽 | 1200x400 | 5 | 最高 |
| 推荐企业位 | RECOMMEND | Banner 下方，4列网格 | 280x200 | 8 | 中高 |
| 列表广告 | LIST | 主内容区域，纵向排列 | 全宽，高90 | 20 | 中等 |
| 侧边栏广告 | SIDEBAR | 页面右侧固定栏 | 200x300 | 4 | 中等 |
| 弹窗广告 | POPUP | 首次访问弹窗 | 500x400 | 1 | 较高 |

#### 设计要点

- **每个广告均带 "广告" 小标识**（右上角 "AD" 角标），合规展示
- **轮播 Banner** 支持自动轮播（5秒间隔）和手动切换
- **推荐企业** 卡片鼠标悬停有阴影加深 + 微上浮动效，点击跳转广告链接
- **列表广告** 左图右文布局，行间有分隔线，清晰整洁
- **侧边栏** 跟随滚动（sticky 定位），不遮挡主内容
- **弹窗广告** 每用户每天仅弹一次（通过 localStorage 记录）
- **响应式设计**：移动端隐藏侧边栏，列表广告改为单列，Banner 自适应高度
- **配色**：与平台主色保持一致，广告区域使用微弱背景色区分

## 四、交互设计要点

### 4.1 用户端交互

| 交互场景 | 设计方案 |
|---------|---------|
| 首次访问 | 自动 IP 定位 → Cookie 记录城市 → 跳转分站 |
| 城市切换 | 导航栏"切换城市"入口，弹出城市选择弹窗 |
| 广告点击 | 新窗口打开链接 + 异步上报点击数据 |
| 广告轮播 | 5 秒自动切换，鼠标悬停暂停，支持手势滑动 |
| 弹窗广告 | 首次访问弹出，关闭后 24 小时内不再弹出 |
| 页面加载 | 骨架屏占位 → 广告数据加载 → 渐入动画 |
| 移动端适配 | Banner 自适应高度，推荐位 2 列，列表单列，隐藏侧边栏 |

### 4.2 管理端交互

| 交互场景 | 设计方案 |
|---------|---------|
| 表单提交 | 提交按钮 loading + 成功/失败 Toast 提示 |
| 删除操作 | 二次确认弹窗，说明影响范围 |
| 图片上传 | 拖拽上传 + 裁剪预览 + 尺寸校验 |
| 数据筛选 | 即时筛选，筛选条件 URL 参数化（可分享/收藏） |
| 批量操作 | 表格支持多选，批量上线/下线/删除 |
| 数据导出 | 广告统计数据支持 Excel 导出 |
