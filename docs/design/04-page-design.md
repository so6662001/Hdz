#### 广告点击跳转说明

用户点击广告时，根据广告配置的 `linkType` 打开对应链接：
- **STORE_PC** → 打开商家在平台上的 PC 版店铺首页
- **STORE_MOBILE** → 打开商家在平台上的移动版店铺首页（移动端自动匹配）
- **OFFICIAL_SITE** → 打开广告主的公司官网
- **CUSTOM** → 打开运营配置的自定义 URL

PC 端使用 `link_url`，移动端优先使用 `link_url_mobile`（为空时降级到 `link_url`）。

## 四、交互设计要点

### 4.1 用户端交互（v2 更新）

| 交互场景 | 设计方案 |
|---------|---------|
| 首次访问（未登录） | 自动 IP 定位 → Cookie 记录城市 → 跳转分站 |
| 首次访问（已登录） | 🆕 查询用户上次分站 → 优先跳转上次分站 → 无记录时走 IP 定位 |
| 再次访问（已登录） | 🆕 自动跳转到上次访问的分站，无需重新选择 |
| 城市切换 | 导航栏"切换城市"入口，切换后更新用户分站记忆 |
| 广告点击 | 🆕 根据设备类型选择 PC/移动端链接 → 新窗口打开 → 异步上报 |
| 招商登记提交 | 🆕 弹窗表单 → 验证码防刷 → 提交成功提示 → 即时企微通知 |
| 广告需求提交 | 🆕 弹窗表单 → 验证码防刷 → 提交成功提示 → 即时企微通知 |
| 广告轮播 | 5 秒自动切换，鼠标悬停暂停 |
| 弹窗广告 | 每用户每天仅弹一次 |
| 页面加载 | 骨架屏占位 → 广告数据加载 → 渐入动画 |
| 移动端适配 | Banner 自适应，推荐位 2 列，列表单列，隐藏侧边栏 |

### 4.2 管理端交互（v2 更新）

| 交互场景 | 设计方案 |
|---------|---------|
| 登记数据查看 | 🆕 列表无删除按钮、无修改按钮，仅"查看"入口 |
| 跟进记录填写 | 🆕 详情页底部追加表单，提交后立即出现在时间线顶部 |
| 跟进记录保护 | 🆕 已提交的跟进记录显示为只读，无编辑/删除按钮 |
| 广告到期调整 | 🆕 待调整状态的广告显示"调整位置"和"续期"按钮 |
| 收费模式切换 | 🆕 选择"赠送"时显示赠送原因输入框；选择"收费"时显示定价方案选择 |
| 企微通知测试 | 🆕 点击"测试"发送测试消息，反馈发送结果 |
| 表单提交 | 提交按钮 loading + 成功/失败 Toast 提示 |
| 数据导出 | 招商登记、广告需求、广告统计均支持 Excel 导出 |
