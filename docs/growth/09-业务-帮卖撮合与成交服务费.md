# 业务线 · 帮卖撮合与成交技术服务费（轻撮合模式）

> 与"线索线"**并行的独立变现业务线**。
> 模式：**平台只做撮合 + 成交确权 + 收取"成交技术服务费"；货权、履约（交付/物流/质检/过磅）、支付全部走线下，平台不碰货、不碰资金、不担履约责任。**
> 本质：把钢贸圈"居间撮合收服务费"这件事产品化、线上化、可对账、可开票。

> 📌 与 `02` 的关系：`02` 第 1.5 节是**线索线**（免费/低价获客、积分激励、目标拉新拉活）；本篇是**成交变现线**（向真实成交收技术服务费）。两条线**商业模式与计费独立**，但**共用同一套归因（`06`）、信用分、成交回填基础设施**。

---

## 1. 业务定位：平台到底卖什么

平台不是"中间商赚差价"，而是**信息技术服务方**，提供并按成交收费的价值是：

- 撮合匹配（资源 ↔ 需求，帮卖人 ↔ 买卖双方）
- 成交确权与对账（线上留痕的成交记录、对账单）
- 信用背书（双方信用分、历史成交、评价）
- 发票/合规（平台开"技术服务费"发票）
- 纠纷协助、行情/曝光等持续权益

> 必须在协议里写清：**平台仅提供信息撮合与技术服务，不对货物质量、交付、付款承担担保或连带责任。** 这是这条线能成立、风险可控的法律前提（务必法务评审）。

---

## 2. 核心难点一：成交确权（钱不过平台，怎么知道成交了、金额多少）

服务费按成交收，所以"**确认一笔成交真实发生 + 确定成交要素**"是整条线的地基。采用**多方确认 + 凭证分级 + 异议期**：

### 2.1 谁来确认（建议三方确认）
- **卖家**确认：在平台点"已成交"，填成交要素。
- **买家**确认：买家在平台确认"已成交"（买家确认可得积分/权益作为激励）。
- **帮卖人**确认：撮合人确认促成（关系到他拿佣金，他会主动盯）。
- 三方互相制衡：任意一方瞒报，另两方有动机举报/确认。

### 2.2 成交要素（确权单字段）
品名 / 规格 / 材质 / 数量(吨) / 单价 / 成交金额 / 交付方式 / 仓库或交货地 / 成交日期 / 关联资源 / 关联帮卖人。

### 2.3 凭证分级（可选但增信，影响费率/信用）
| 等级 | 凭证 | 用途 |
|------|------|------|
| 弱 | 双方点击确认 | 基础确权 |
| 中 | 合同/采购单/聊天记录截图 | 提高可信、减少异议 |
| 强 | 磅单/送货单/付款凭证 | 用于大额、争议、信用加分 |

### 2.4 异议期与申诉
- 确权后设 N 天异议窗口；任一方可申诉（金额不符、未实际成交、重复等），平台仲裁。
- 确权稳定后才正式计费，避免误收。

---

## 3. 核心难点二：服务费的"可收性"（钱不过平台，怎么收上来）

钱在线下走，平台收费天然有"收不上来"的风险。**不要默认"先撮合后按笔追着收"**，那样坏账高、催收累。按推荐优先级组合：

### 3.1 预付费"服务费钱包"（强烈推荐为主）
- 商家先充值技术服务费余额；成交确权后**从余额自动扣减**。
- 余额不足 → 暂停撮合/曝光/帮卖资格。
- 优点：**把"事后收款难"变成"事前已收钱"**，平台零坏账、现金流好。

### 3.2 会员 / 套餐制（推荐为主，最省心）
- 包年/包月会员：免单笔服务费 或 含 N 笔额度/N 吨额度。
- 把"按笔难收"转成"预收年费"，彻底规避单笔收款难题，并锁定现金流与续费黏性。
- 适合高频卖家；低频卖家走 3.1 预付钱包。

### 3.3 保证金 / 押金（辅助）
- 入驻交保证金，欠费/违约从保证金扣，余额不足须补缴。

### 3.4 信用账期 + 月对账单（仅给优质大客户）
- 先撮合、月底出账单、对公付款。需**信用风控 + 授信额度 + 催收**，有坏账风险，仅对高信用大客户开放。

### 3.5 后付费 + 信用约束（兜底）
- 欠费则降权、限流、停撮合、上黑名单、扣信用分；信用分公开影响其在平台的获客能力。

> **落地建议：以"会员套餐 + 预付钱包"为主，信用账期只给优质大客户。** 这样在"支付不过平台"的前提下，依然能稳定、低坏账地把服务费收上来。

---

## 4. 计费规则设计

### 4.1 向谁收
- **默认向卖家收**（卖家是获客受益方）；也可买卖各半，或配置化。
- 帮卖人佣金与平台技术服务费**分开**（见第 5 节），别混为一谈。

### 4.2 怎么收
- 按成交额比例（如 0.X%~X%）/ 按吨固定（X 元/吨）/ 二者取一。
- **设单笔封顶**：大单服务费封顶，避免大额成交被费率劝退而飞单。
- 阶梯费率：成交越多费率越低（鼓励留在平台、做大量）。
- 会员减免：会员按套餐免除或打折。
- 全部费率规则**后台配置化**，便于按品类/区域/客户分层定价。

---

## 5. 帮卖人佣金怎么给（钱在线下时）

平台技术服务费是**平台的收入**；帮卖人的佣金是**卖家付给撮合人的钱**，两者要分清：

- **方式 A（线下付，平台见证）**：卖家线下付佣金给帮卖人，平台只**记录佣金约定 + 出佣金对账单 + 信用背书**，降低赖账概率。
- **方式 B（平台积分/平台币结算）**：帮卖佣金用平台积分/权益结算，平台可控，不涉资金合规。
- **方式 C（资金接入后）**：平台代收代付佣金（未来演进，本阶段不做）。

> 现阶段建议 A + B 组合：大额佣金走"线下付 + 平台对账见证"，日常激励用积分。

---

## 6. 最大经营风险：飞单 / 跳单（双方私下成交逃服务费）

买卖双方认识后跳过平台私下成交，是这条线的头号风险。对抗组合拳：

1. **预付/会员制天然减飞单**：钱已预付，单笔逃费动机大幅下降（首选）。
2. **持续价值绑定**：平台给的不只是一次撮合，还有持续线索、曝光、行情、信用资产、对账开票、纠纷协助——让商家觉得"这服务费值，跳单不划算"。
3. **费率别太狠 + 封顶**：让"逃费收益 < 麻烦 + 信用损失"。
4. **信用资产沉淀在平台**：评价、历史成交、信用分都在平台，跳单=损失信用资产、影响后续获客。
5. **诚实回填有正收益**：回填成交给曝光/信用/积分回馈，让回填不是纯成本。
6. **双边制衡**：买家确认成交得权益，一方瞒报另一方可举报。
7. **接受一定漏报率**：现实中抓不全，靠"性价比 + 价值"让多数人自愿走平台，而非靠强管控。

---

## 7. 全流程

```
帮卖人撮合 / 资源-需求匹配
   → 买卖双方达成意向(线下谈)
   → 任一方在平台发起"成交确权单"(填要素, 可传凭证)
   → 三方确认(卖家/买家/帮卖人) → 进入异议期(N天)
   → 确权成立
   → 计费引擎按规则算技术服务费 → 从卖家"服务费钱包"扣 / 计入会员额度 / 入月账单
   → 平台开具技术服务费发票
   → 帮卖佣金: 卖家线下付帮卖人(平台出对账单见证) 或 平台积分结算
   → 双方互评 → 信用分/成交榜沉淀 → 反哺撮合与曝光
```

## 8. 与线索线如何衔接（用户要求两条线分开，但要协同）

| | 线索线（`02` §1.5） | 成交服务费线（本篇） |
|---|---|---|
| 目标 | 拉新、拉活、获客 | 变现 |
| 交付物 | 合格线索 | 真实成交 + 服务费 |
| 收费 | 免费/低价，积分激励 | 向成交收技术服务费 |
| 触发 | 留资 / 帮卖带客 | 成交确权 |
| 共用基础设施 | 归因(`06`)、信用分、成交回填、商家工作台 |

衔接点：**线索 → 撮合 → 成交确权 → 收服务费**，是同一漏斗的不同深度。线索线负责把人和需求引进来并养信任；成交线负责在成交那一刻变现。两条线计费独立、可分别上线，但数据互通。

---

## 9. 风控与合规（务必）

- **协议定性**：平台为信息技术/撮合服务方，不担保货物与履约，不承担交易连带责任（法务评审）。
- **发票税务**：平台开"技术服务费"发票，税务合规；会员/预付的收入确认规则清晰。
- **确权防伪**：防虚假成交骗曝光/刷信用/刷帮卖佣金；凭证审核、异议仲裁、异常成交监控。
- **价格与反垄断/反操纵**：撮合不操纵价格。
- **信息安全**：成交数据、联系方式按权限脱敏，防倒卖。

---

## 10. 研发增量（相对线索线新增的部分）

- **成交确权服务**：确权单、三方确认、凭证上传分级、异议期、状态机（待确认/确权中/已确权/异议/作废）。
- **计费引擎**：费率规则（比例/按吨/阶梯/封顶/会员减免）、计费计算、可配置。
- **商家费用账户**：服务费钱包（充值/扣减）、会员套餐与额度、保证金、信用账期与月对账单、欠费状态。
- **发票/对公收款对接**。
- **帮卖佣金记录**：佣金约定、对账单、（积分）结算。
- **信用与反飞单**：信用分、评价体系、异常/漏报监控。
- **复用**：归因(`06`)、激励积分(`05`)、商家工作台、用户/企业认证。

> 可不做：在线支付、担保交易、平台代收货款、履约/物流（全部线下）。这正好让这条线**轻、快、合规风险可控**。

---

## 11. 给老板的一句话

> 这条线让平台从"免费给线索"升级为"按成交收技术服务费"的变现业务：**平台只做撮合、确权、收费、开票，绝不碰货和钱**；靠"会员 + 预付钱包"解决"钱不过平台也能稳收费"，靠"三方确权 + 信用资产 + 合理费率"对抗飞单。它和线索线共用一套底座，可以独立上线、独立计费，是平台最直接的盈利引擎。
