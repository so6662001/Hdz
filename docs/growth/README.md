# 钢铁贸易平台 · 裂变增长设计方案

> 以"营销总裁 + 平台运营官"视角，为钢贸 B2B 平台设计的一整套**裂变增长玩法 + 可落地研发方案**。
> 核心诉求：帮商家/卖家**推广引流、获客（线索）**，让商家、卖家、买家、平台**都能自发裂变**。

## 一句话总结

> 不靠平台自己花钱拉人，而是把**行情变成商家的人设海报、资源变成全员可分销的提成商品、采购变成买家自发组织的拼单团**，再用积分任务和大促调度节奏；底层用"追踪归因 + 激励结算"引擎，保证**谁带来的客户算谁的、该给的钱自动结**，让三方都为自己的利益替平台做裂变。

## 重要提醒

- **先做地基**：追踪归因引擎（`06`）+ 激励引擎（`05`）是一切玩法的前提，优先开发。
- **合规红线**：多级分销的层级与计酬方式必须经法务评审，佣金须挂钩真实交易，严禁"拉人头计酬"。
- **B2B 特性**：大额、低频、重履约——拼单/帮卖必须配套担保交易、资金托管与履约规则。
