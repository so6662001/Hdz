# 玩法三 · 拼单团购（凑量降本裂变）

> 一句话：**让买家为了"拿到更低的价格 / 凑够钢厂起订量 / 拼省运费"而主动拉同行进来——买得越多、拉得越多，越便宜。**
> 这是买家侧最强的裂变动机：拉人不是为平台，是为自己省钱。

---

## 1. 行业洞察：钢贸天然存在"凑量"需求

- 钢厂、大贸易商往往有**起订量 / 整车 / 整批**门槛，小买家单独吃不下或拿不到好价。
- 价格随量阶梯下降：量越大，单价越低（这是钢贸常识）。
- 物流（整车 vs 零担）也随凑量而降本。
- 所以"找几个同行一起订"在线下早就存在 —— 我们把它做成**线上拼单**，并加上"拉人享更低价"的裂变机制。

---

## 2. 子玩法清单

### 2.1 凑量拼单（达量直发价）
商家/钢厂发布一个拼单："拼满 N 吨，享受 XX 元/吨的钢厂直发价"。

- 买家加入 → 实时显示"已拼 X 吨 / 目标 N 吨，还差 Y 吨"。
- 差量时自动催拼："再拉 1 家就成团" → 制造紧迫感和拉人动机。
- 成团则全员享低价；未成团自动退款/转下一期。

### 2.2 阶梯拼单（拼得越多越便宜，主力裂变款）
价格随拼单总量阶梯下降，**每个人都希望别人也来拼**，于是自发拉人。

```
拼单总量阶梯（示例）：
   < 30 吨   →  4200 元/吨
  30~100 吨  →  4150 元/吨
  100~300 吨 →  4100 元/吨
  > 300 吨   →  4050 元/吨   ← 大家一起努力拉到这一档
```

- 关键体验："**你拉来的人下的量，也帮你拉低了你的单价**" → 强拉人激励。
- 实时进度条 + 当前档位 + 下一档还差多少 → 可视化驱动转发。

### 2.3 团长制（KOL/居间人组团）
有号召力的人（大贸易商、活跃居间人、区域 KOL）当**团长**，发起并组织拼单。

- 团长职责：发起拼单、拉人、协调、（可选）做履约对接。
- 团长激励：服务费/返利/积分（基于真实成团量，合规挂钩交易）。
- 团长榜单：成团量排行，给荣誉和资源位。
- 这本质是把"帮卖分销"和"拼单"结合：团长既拉人又组货。

### 2.4 拼车物流（同向凑运费）
同一方向/同一仓库出货的订单，拼一辆车，**分摊运费、降低单家物流成本**。

- 发布"拼车需求"（出发地/目的地/时间窗/可拼吨位），招募同向货主。
- 物流是钢贸隐性大成本，拼车是真实痛点，自带传播力。

### 2.5 预售拼单 / 接龙团（清库存 + 锁单）
- 商家清库存或锁定未来产能时发"预售拼单"，买家接龙下定金。
- 群内"接龙"形态非常符合钢贸微信群习惯，转发即接龙、接龙即裂变。

---

## 3. 拉人裂变机制（怎么让买家自发拉人）

| 机制 | 说明 | 驱动力 |
|------|------|--------|
| 价格联动 | 总量越大单价越低，别人拼也让我变便宜 | 经济利益（最强） |
| 成团门槛 | 差一点就成团，催着拉最后一脚 | 损失厌恶/紧迫感 |
| 拼单海报 | 一键生成"我发起了拼单，还差 X 吨"海报转发 | 便捷传播 |
| 团长返利 | 组团者按成团量拿激励 | 组织者动机 |
| 限时 | 倒计时，过期不候 | 紧迫感 |
| 进度可视化 | 进度条/差额/档位实时刷新 | 即时反馈，促转发 |

---

## 4. 用户旅程示例

```
团长(大贸易商)老张 发起阶梯拼单"螺纹钢HRB400E φ16，目标冲到300吨档(4050/吨)"
  → 老张生成拼单海报转到 5 个钢贸群(带追踪码)
  → 同行各自下单，进度条到 120 吨(当前4100/吨)
  → 系统提示"再拼 180 吨可降到 4050，省 50元/吨"
  → 已参团的人也开始转发拉人(因为别人拼=自己更便宜)
  → 冲到 300+ 吨成团，全员享 4050；老张拿团长服务费
  → 参团的新用户(此前没注册过)成为平台用户+线索，归因到分享者
```

裂变来源：团长 1→N 拉群 + 参团人因价格联动 1→N 二次拉人 + 新人成为下次拼单的发起者。

## 5. 履约与资金（B2B 必须想清楚）

拼单不是发个团就完了，**B2B 大额交易的履约和资金安全是成败关键**：

- **资金**：建议走平台担保交易 / 第三方支付托管，成团后再付钢厂/商家，未成团自动退。
- **价格有效性**：钢价波动大，拼单需设"价格有效期 + 锁价机制"（成团即锁价，或定金锁价、尾款随行）。
- **履约**：明确发货、提货、质检、过磅、磅差处理、退换规则；建议接入平台物流/仓储或可信第三方。
- **分货**：拼单到货后如何分给各买家（统一过磅、分单提货），需要清晰规则与单据。
- **风险提示**：钢价单边下跌时买家可能毁约，需定金/违约金条款。

> 拼单的运营很性感，但**履约和资金风控是真正的工程**，建议先从"商家自有库存现货拼单 + 平台担保 + 短账期"这种低风险形态切入，再逐步做钢厂直发、预售。

---

## 6. 风控与合规

- 防恶意凑量后集体毁约：定金 + 信用分 + 黑名单。
- 防虚假拼单（假装成团骗定金）：商家资质审核 + 担保交易 + 平台兜底规则。
- 团长激励合规挂钩真实成团交易，避免"拉人头计酬"。
- 价格合规：避免操纵价格、虚标原价等问题。

## 7. 研发拆解（给技术）

- **拼单活动服务**：拼单创建（凑量/阶梯/拼车/预售）、规则配置（目标量、阶梯价、时间窗、起订量）、状态机（拼中/成团/失败/履约中/完成）。
- **实时进度与档位计算**：累计量、当前档位、差额提示，需高并发下的库存与计数一致性。
- **下单与担保支付**：下单、定金/全款、托管、成团触发支付、失败退款。
- **团长与归因**：团长关系、分享追踪（接 `06`）、激励结算（接 `05`）。
- **履约模块**：发货/提货/过磅/分货单据、磅差与退换。
- **拼车物流**：路线/吨位匹配、运费分摊。
- 数据模型与 API 见 [`07-研发-技术架构与数据模型.md`](./07-研发-技术架构与数据模型.md)。

---

## 8. 定位

- **行情裂变**起量、**帮卖分销**变现获客、**拼单团购**则是把买家侧的真实采购需求组织起来，直接产生大额 GMV，并让买家成为裂变主角。三者叠加，卖家、买家、平台都有自发裂变的理由。
