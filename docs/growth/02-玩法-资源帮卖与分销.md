# 玩法二 · 资源帮卖与分销（全员卖货裂变）

> 一句话：**把钢贸圈"互相介绍买卖、赚个差价/人情"这件本来就在发生的事，产品化、可追踪、可结算——让任何人都能"帮卖"别人的货并拿佣金。**
> 这是 B2B 钢贸最强的裂变引擎，因为它直接对应真金白银的赚钱动机。

---

## 1. 行业洞察：钢贸本来就是"分销社会"

钢贸圈的真实生态：钢厂 → 大贸易商 → 二级商 → 终端，中间还有大量"居间人/信息中介"靠撮合赚差价。**"我手上有货，你帮我找买家，成交分你钱"本来就天天发生，只是在微信、电话、饭桌上完成，平台抓不到、沉淀不了。**

我们要做的不是发明新行为，而是**把这个旧行为搬到线上、加上追踪和结算**，于是：
- 每一次"帮卖"都变成平台的一次传播和一条线索；
- 每一个"居间人"都变成平台的免费分销员；
- 商家的获客成本从"自己投广告"变成"成交才付佣金"（CPS，按效果付费），零风险。

---

## 2. 子玩法清单

### 2.1 资源海报 / 资源微名片（人人可转发）
商家上架一条资源（品名/规格/材质/数量/产地/价格/仓库），**一键生成资源海报或资源卡片**，任何人都能转发。

- 海报含：资源信息 + 转发人的名片/二维码 + 追踪码。
- 谁转发、谁带来的留资/成交，归因到谁。
- 商家自己转 = 自获客；别人转 = 帮卖（见下）。

### 2.2 一键帮卖 / CPS 分销（核心）
任意用户在任意一条资源上点"**帮卖赚佣金**"，生成自己的专属帮卖链接/海报。

- **佣金规则由资源发布方设定**：固定金额（如 20 元/吨）或按比例，平台可设抽佣。
- 成交并确认后，佣金自动结算给帮卖人（接激励引擎的"佣金账户"）。
- 帮卖人不需要垫钱、不需要囤货、不接触货权，只负责"带客"，降低参与门槛 → 人人可参与 → 裂变面最大。
- 风险控制：佣金在"成交确认 / 回款确认"后释放，避免刷单。

### 2.3 多级分销（谨慎设计，建议二级封顶）
支持"我帮卖的人，又招到下家帮卖"，上级拿一点点二级佣金。

- **强烈建议最多二级（直推 + 间推），并明确合规边界**：国内对"多级分销/团队计酬"有法律红线（传销认定），层级和计酬方式必须合规，**佣金必须基于真实交易，不能基于"拉人头本身"**。
- 二级佣金比例要低，主要起"激励老分销员去带新分销员"的作用。
- 该子玩法上线前务必走法务评审（见风控章节）。

### 2.4 商家的"销售军团"（员工 + 圈子裂变）
给商家一个"**招募帮卖员**"的功能：商家把自己的员工、熟客、同行发展成帮卖员。

- 商家后台可看：每个帮卖员带来多少访问/线索/成交，发了多少佣金。
- 商家可设"专属佣金""指定资源帮卖""帮卖排行榜 PK"激励自己的军团。
- 本质：**平台帮商家搭建了一套零成本的分销 SCRM**，商家越用越离不开平台。

### 2.5 求购大厅 + 找货悬赏（反向裂变）
买家发布求购（要什么货、多少量、什么价位），**发动人脉帮找货**。

- "**找货悬赏**"：找到合适货源并促成成交，赏金给找货人 → 反向激励传播。
- 求购信息可一键转发到社群/朋友圈（带追踪码），形成"求购也能裂变"。
- 平台/商家看到求购 = 精准采购线索，可主动报价（撮合）。

### 2.6 资源拼图 / 凑货（接拼单）
"我这条资源量大，单个买家吃不下" → 转发招募一起吃货的人 → 进入拼单流程（见 [`03-玩法-拼单团购.md`](./03-玩法-拼单团购.md)）。

---

## 3. 角色与动机对照

| 角色 | 在帮卖分销里做什么 | 动机 |
|------|------------------|------|
| 卖货商家 | 设佣金、招帮卖员、看数据 | 按成交付佣金，零风险获客、清库存 |
| 帮卖人（同行/居间/员工/任何人） | 转发资源、带客、撮合 | 成交拿佣金，把人脉变现 |
| 买家 | 发求购、设悬赏、收资源 | 更快买到、更便宜、有人帮找货 |
| 平台 | 提供工具、追踪、结算、抽佣 | 沉淀交易与线索、形成网络效应、抽佣变现 |

---

## 4. 关键流程：帮卖成交与佣金结算

```
商家发布资源(设佣金) → 帮卖人A点"帮卖"生成专属码 → A转发到社群/朋友圈
   → 买家B通过A的码进入 → 留资/下单(归因=A,商家=资源方)
   → 商家与B线下/线上完成交易 → 平台确认成交(或回款)
   → 佣金从"冻结"转"可提现"打入A的佣金账户 → A可提现/转积分
   → A看到收益 → 继续帮卖更多资源(自转)
```

**结算时点是风控关键**：佣金不在"留资"时发，而在"成交/回款确认"后发，从根本上杜绝"为骗佣金乱拉人"。

---

## 5. 激励与定价（接 `05` 激励引擎）

- 佣金账户：冻结 / 可提现 / 已提现三态；提现走对公或微信，需税务/发票合规。
- 平台抽佣：可对帮卖佣金抽成，或对商家收"成交服务费"。
- 排行榜：帮卖王榜、商家成交榜，月度激励 + 荣誉。
- 与积分体系联动：佣金可选择转积分（积分有溢价，鼓励留在平台生态内消费）。

---

## 6. 风控与合规（重点，必须做）

1. **合规第一**：多级分销层级与计酬方式须经法务评审，避免触碰传销红线；佣金必须挂钩真实交易。
2. **防刷单**：佣金成交后结算 + 异常交易识别（同主体自买自卖、价格异常、关联账户）。
3. **资源真实性**：上架资源审核（资质、货权、价格合理性），打击虚假低价资源引流。
4. **资金合规**：佣金提现的税务、发票、对公流程；大额走平台担保交易更安全。
5. **信息归属与隐私**：买家联系方式按规则脱敏分配，防止线索被恶意爬取。

---

## 7. 研发拆解（给技术）

- **资源中心**：资源发布/审核/上下架、规格化字段（品名/规格/材质/产地/仓库/数量/价格/佣金规则）。
- **帮卖关系服务**：用户-资源的帮卖关系、专属码、归因（接 `06`）。
- **分销关系链**：上下级关系（二级封顶）、佣金计算规则引擎。
- **佣金账户与结算**：账户三态、结算触发（成交/回款事件）、提现、抽佣、对账。
- **求购与悬赏**：求购发布、悬赏托管与释放、撮合匹配。
- 数据模型与 API 见 [`07-研发-技术架构与数据模型.md`](./07-研发-技术架构与数据模型.md)。

---

## 8. 为什么这是"GMV + 线索"双杀的玩法

行情裂变带来的是**流量和人设**；帮卖分销带来的是**真实成交和精准线索**。它把平台从"信息平台"升级为"交易+分销平台"，商家黏性、平台抽佣空间、数据壁垒都在这一层建立。
