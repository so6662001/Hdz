# 玩法二 · 资源帮卖与分销（全员卖货裂变）

> 一句话：**把钢贸圈"互相介绍买卖、赚个差价/人情"这件本来就在发生的事，产品化、可追踪、可结算——让任何人都能"帮卖"别人的货并拿佣金。**
> 这是 B2B 钢贸最强的裂变引擎，因为它直接对应真金白银的赚钱动机。

> ⚠️ **现阶段说明（必读）**：平台**尚未接入在线成交与资金模块**，买家下单后在线下自行成交，平台现阶段**以"线索"为核心交付物**。
> 因此本玩法在现阶段需从"以成交结算（CPS）为核心"调整为"**以线索为核心（CPL/CPA）**"。
> 完整的现阶段适配方案见下方 [**第 1.5 节 · 现阶段适配方案**](#15-现阶段适配方案无在线成交与资金以线索为核心)。本文其余章节（CPS、佣金账户、担保结算等）作为**资金模块接入后的演进目标**保留。

---

## 1. 行业洞察：钢贸本来就是"分销社会"

钢贸圈的真实生态：钢厂 → 大贸易商 → 二级商 → 终端，中间还有大量"居间人/信息中介"靠撮合赚差价。**"我手上有货，你帮我找买家，成交分你钱"本来就天天发生，只是在微信、电话、饭桌上完成，平台抓不到、沉淀不了。**

我们要做的不是发明新行为，而是**把这个旧行为搬到线上、加上追踪和结算**，于是：
- 每一次"帮卖"都变成平台的一次传播和一条线索；
- 每一个"居间人"都变成平台的免费分销员；
- 商家的获客成本从"自己投广告"变成"成交才付佣金"（CPS，按效果付费），零风险。

## 1.5 现阶段适配方案（无在线成交与资金，以线索为核心）

> 这是针对"平台还没有成交/资金模块、买家线下自行成交、平台以线索为核心"现状的落地版设计。
> 核心动作：**把"帮卖成交分佣（CPS）" → 调整为"帮卖获客拿激励（CPL/CPA）"**，并用一套不依赖资金、也不怕刷的机制替代"资金作为防刷闸门"的作用。

### 1.5.1 一句话定位
现阶段帮卖人交付的不是"成交"，而是"**合格线索**"。所以激励要挂在**线索漏斗**上，而不是挂在成交金额上。

### 1.5.2 激励货币：积分/权益为主，现金为辅，大钱延后
没有资金模块时不要急着发现金佣金（有合规/税务/提现压力，又难防刷）：

| 激励 | 用途 | 说明 |
|------|------|------|
| **积分 / 成长值 / 权益（主）** | 日常帮卖、带来线索 | 平台自己可控、零资金合规；出口给足：兑**线索额度、店铺曝光位、会员、抽奖、平台周边** |
| **小额现金红包（辅）** | 关键拉新动作点火 | 小额、人工审核、设上限，仅用于撬动启动 |
| **大额回报（延后）** | 成交回填确认后发放 | 等于把 CPS 延后到"商家手动确认成交"那一刻，详见 1.5.4 |

### 1.5.3 把激励挂在"线索漏斗"上，用商家确认替代资金闸门
资金不再当防刷闸门，就让**商家的逐级确认动作**当闸门——商家天然有动力对真线索点"有效"、对假线索点"无效"，相当于让商家替平台做线索质检和反作弊。

| 阶段 | 触发条件 | 奖励 | 防刷点 |
|------|---------|------|--------|
| **L1 有效线索** | 被带来的人完成实名+企业认证、有真实需求与可联系方式 | 小额积分 | 认证去重、防小号 |
| **L2 商家受理** | 商家后台把线索标记为"有效 / 跟进中" | 中额积分 / 小红包 | 商家不会给假线索点"有效" |
| **L3 成交回填** | 商家标记"已成交"（可选填吨数/金额、传合同/磅单/聊天截图） | 大额积分 / 现金 | 双向确认 + 凭证 |

> 原则：**奖励大头放在 L2、L3**，因为它们都需要商家主动确认；L1 只给"够启动"的小奖励，防止有人为了 L1 小积分批量灌假线索。

### 1.5.4 "成交回填"：解决线下成交看不见的数据缺口
线下成交平台观测不到，就**设计动机让商家主动回填**：

- **回填能换好处**：提升店铺"成交榜 / 诚信标"→ 更多曝光与免费线索额度；回填越多，平台越愿意给流量。
- **帮卖人催回填**：帮卖人的大额奖励依赖商家回填，会主动催商家确认（社会监督，自然闭环）。
- **双向确认防瞒报/虚报**：买家也确认"已成交"并得积分 → 交叉验证真实性。
- **数据价值**：这套回填的成交/吨数/金额数据，是未来接入资金与担保交易前最宝贵的 GMV 与转化率积累。

### 1.5.5 线索质量与防刷（资金不再把关，这里必须加强）
- 强制**实名 + 企业认证**才算有效线索；同手机号 / 同企业去重。
- 商家给每条线索打标签（有效 / 无效 / 重复 / 骚扰），反向计入帮卖人的**信用分**。
- 帮卖人信用分低 → 降权、降激励、限流甚至封禁；信用分高 → 更高积分系数、优先派单。
- 防自我留资、关联账户互刷（设备指纹 + 关系图谱，见 [`06`](./06-引擎-分享追踪与线索归因.md)）。

### 1.5.6 语义与产品微调
- 把帮卖带来的"下单"明确叫"**采购意向单 / 报价请求**"——本质是高质量线索，给更高激励权重。
- 商家端核心是"**线索看板 + 一键拨号/加企微 + 状态流转 + 成交回填**"工作台，这是现阶段平台真正交付给商家的产品。
- 求购悬赏（见 2.5）同样改为"促成成交由商家回填确认后释放赏金 / 积分"。

### 1.5.7 平滑演进路径（给未来留接口）
| 阶段 | 形态 | 结算 |
|------|------|------|
| **A 现在** | 线索为核心 | 积分激励 + 商家成交回填（弱验证） |
| **B 过渡** | 回填加双向确认 + 凭证 | 开放小额现金佣金（人工审核） |
| **C 资金接入后** | 在线担保交易 | CPS 自动结算（本文 §4 的完整形态） |

> 关键：A→B→C 全程复用同一套**归因关系、信用分、成交回填习惯**，不返工。现在做的每一步都是未来的地基。

### 1.5.8 现阶段研发增量（相对 §7 的精简）
- **可先不做**：佣金资金账户、提现、担保支付、在线成交。
- **必须做**：线索漏斗状态机（L1/L2/L3）、商家线索工作台（受理/打标签/成交回填）、积分激励、帮卖人信用分、归因与防刷。
- 这样现阶段就能跑通完整的"帮卖获客闭环"，且与资金模块解耦。

## 2. 子玩法清单

### 2.1 资源海报 / 资源微名片（人人可转发）
商家上架一条资源（品名/规格/材质/数量/产地/价格/仓库），**一键生成资源海报或资源卡片**，任何人都能转发。

- 海报含：资源信息 + 转发人的名片/二维码 + 追踪码。
- 谁转发、谁带来的留资/成交，归因到谁。
- 商家自己转 = 自获客；别人转 = 帮卖（见下）。

### 2.2 一键帮卖 / CPS 分销（核心）
> 📌 现阶段（无资金模块）：把下文"佣金成交结算"替换为 [1.5 节](#15-现阶段适配方案无在线成交与资金以线索为核心)的"积分 + 成交回填"方案；以下 CPS 资金形态为资金接入后的目标态。

任意用户在任意一条资源上点"**帮卖赚佣金**"，生成自己的专属帮卖链接/海报。

- **佣金规则由资源发布方设定**：固定金额（如 20 元/吨）或按比例，平台可设抽佣。
- 成交并确认后，佣金自动结算给帮卖人（接激励引擎的"佣金账户"）。
- 帮卖人不需要垫钱、不需要囤货、不接触货权，只负责"带客"，降低参与门槛 → 人人可参与 → 裂变面最大。
- 风险控制：佣金在"成交确认 / 回款确认"后释放，避免刷单。

### 2.3 多级分销（谨慎设计，建议二级封顶）
支持"我帮卖的人，又招到下家帮卖"，上级拿一点点二级佣金。

- **强烈建议最多二级（直推 + 间推），并明确合规边界**：国内对"多级分销/团队计酬"有法律红线（传销认定），层级和计酬方式必须合规，**佣金必须基于真实交易，不能基于"拉人头本身"**。
- 二级佣金比例要低，主要起"激励老分销员去带新分销员"的作用。
- 该子玩法上线前务必走法务评审（见风控章节）。

### 2.4 商家的"销售军团"（员工 + 圈子裂变）
给商家一个"**招募帮卖员**"的功能：商家把自己的员工、熟客、同行发展成帮卖员。

- 商家后台可看：每个帮卖员带来多少访问/线索/成交，发了多少佣金。
- 商家可设"专属佣金""指定资源帮卖""帮卖排行榜 PK"激励自己的军团。
- 本质：**平台帮商家搭建了一套零成本的分销 SCRM**，商家越用越离不开平台。

### 2.5 求购大厅 + 找货悬赏（反向裂变）
买家发布求购（要什么货、多少量、什么价位），**发动人脉帮找货**。

- "**找货悬赏**"：找到合适货源并促成成交，赏金给找货人 → 反向激励传播。
- 求购信息可一键转发到社群/朋友圈（带追踪码），形成"求购也能裂变"。
- 平台/商家看到求购 = 精准采购线索，可主动报价（撮合）。

### 2.6 资源拼图 / 凑货（接拼单）
"我这条资源量大，单个买家吃不下" → 转发招募一起吃货的人 → 进入拼单流程（见 [`03-玩法-拼单团购.md`](./03-玩法-拼单团购.md)）。

## 3. 角色与动机对照

| 角色 | 在帮卖分销里做什么 | 动机 |
|------|------------------|------|
| 卖货商家 | 设佣金、招帮卖员、看数据 | 按成交付佣金，零风险获客、清库存 |
| 帮卖人（同行/居间/员工/任何人） | 转发资源、带客、撮合 | 成交拿佣金，把人脉变现 |
| 买家 | 发求购、设悬赏、收资源 | 更快买到、更便宜、有人帮找货 |
| 平台 | 提供工具、追踪、结算、抽佣 | 沉淀交易与线索、形成网络效应、抽佣变现 |

## 4. 关键流程：帮卖成交与佣金结算
> 📌 本节为**资金模块接入后**的目标态流程。现阶段请以 [1.5 节](#15-现阶段适配方案无在线成交与资金以线索为核心)的"线索漏斗 + 成交回填 + 积分"流程为准。

```
商家发布资源(设佣金) → 帮卖人A点"帮卖"生成专属码 → A转发到社群/朋友圈
   → 买家B通过A的码进入 → 留资/下单(归因=A,商家=资源方)
   → 商家与B线下/线上完成交易 → 平台确认成交(或回款)
   → 佣金从"冻结"转"可提现"打入A的佣金账户 → A可提现/转积分
   → A看到收益 → 继续帮卖更多资源(自转)
```

**结算时点是风控关键**：佣金不在"留资"时发，而在"成交/回款确认"后发，从根本上杜绝"为骗佣金乱拉人"。

## 5. 激励与定价（接 `05` 激励引擎）

- 佣金账户：冻结 / 可提现 / 已提现三态；提现走对公或微信，需税务/发票合规。
- 平台抽佣：可对帮卖佣金抽成，或对商家收"成交服务费"。
- 排行榜：帮卖王榜、商家成交榜，月度激励 + 荣誉。
- 与积分体系联动：佣金可选择转积分（积分有溢价，鼓励留在平台生态内消费）。

---

## 6. 风控与合规（重点，必须做）

1. **合规第一**：多级分销层级与计酬方式须经法务评审，避免触碰传销红线；佣金必须挂钩真实交易。
2. **防刷单**：佣金成交后结算 + 异常交易识别（同主体自买自卖、价格异常、关联账户）。
3. **资源真实性**：上架资源审核（资质、货权、价格合理性），打击虚假低价资源引流。
4. **资金合规**：佣金提现的税务、发票、对公流程；大额走平台担保交易更安全。
5. **信息归属与隐私**：买家联系方式按规则脱敏分配，防止线索被恶意爬取。

## 7. 研发拆解（给技术）

- **资源中心**：资源发布/审核/上下架、规格化字段（品名/规格/材质/产地/仓库/数量/价格/佣金规则）。
- **帮卖关系服务**：用户-资源的帮卖关系、专属码、归因（接 `06`）。
- **分销关系链**：上下级关系（二级封顶）、佣金计算规则引擎。
- **佣金账户与结算**：账户三态、结算触发（成交/回款事件）、提现、抽佣、对账。
- **求购与悬赏**：求购发布、悬赏托管与释放、撮合匹配。
- 数据模型与 API 见 [`07-研发-技术架构与数据模型.md`](./07-研发-技术架构与数据模型.md)。

## 8. 为什么这是"GMV + 线索"双杀的玩法

行情裂变带来的是**流量和人设**；帮卖分销带来的是**真实成交和精准线索**。它把平台从"信息平台"升级为"交易+分销平台"，商家黏性、平台抽佣空间、数据壁垒都在这一层建立。
