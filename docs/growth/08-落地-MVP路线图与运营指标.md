# 落地 · MVP 路线图与运营指标

> 怎么分阶段开发、先做什么、怎么衡量成功。原则：**先打地基 + 一个低成本爆点起量，再上变现裂变，最后做平台调度层。**
> （按技术依赖和风险排序，不按日历周期排期。）

---

## 1. 分阶段路线图

### 阶段 0 · 地基（必须最先做）
**目标：让"谁分享、谁带来、算谁的"跑通，奖励能发能核销。**

- 追踪归因引擎（`spread_code`、短链/二维码、触点事件、首次/末次归因、线索归属）。
- 激励引擎（统一账户、流水、奖励规则引擎、积分）。
- 基础风控（幂等、上限、设备指纹、新用户有效性校验）。
- 用户/企业认证、海报生成服务。

> 没有阶段 0，后面任何玩法都无法正确发奖/分配线索。**这是优先级最高、最先开发的部分。**

### 阶段 1 · 行情裂变（第一个爆点，低成本起量）
**目标：用最低成本、最高频的内容把日活和裂变跑起来，验证地基。**

- 行情数据 + 个人 IP 行情海报（一键生成带名片追踪码）。
- 行情订阅 + 解锁（邀请解锁高级行情）。
- 行情竞猜（日活互动）。
- 社群一键分发 + 群专属码。
- 验证指标：行情海报分享率、海报带来的留资数、邀请解锁拉新数、K 因子。

### 阶段 2 · 变现裂变（资源帮卖 + 拼单）
**目标：从"流量/线索"升级到"真实成交 + GMV"。**

- 资源中心 + 资源海报 + 一键帮卖。
  - **现阶段（无资金模块）先做 CPL/CPA 版**：线索漏斗（L1 有效线索 / L2 商家受理 / L3 成交回填）+ 积分激励 + 帮卖人信用分 + 商家线索工作台（受理/打标签/成交回填）。详见 `02` 第 1.5 节。
  - CPS 佣金/佣金账户/提现/担保结算等**待资金模块接入后再上**（演进阶段 B→C）。
- 商家"销售军团"看板。
- 求购大厅 + 找货悬赏（赏金改为成交回填确认后释放积分/奖励）。
- **（可并行/独立上线）帮卖撮合成交技术服务费业务线**：成交确权（三方确认+凭证+异议期）+ 计费引擎 + 商家"服务费钱包/会员套餐" + 发票，**货权/履约/支付全走线下**。详见 `09`。建议优先用"会员 + 预付钱包"解决"钱不过平台也能稳收费"，规避坏账。
- 拼单团购（现阶段无在线资金版，详见 `03` §1.5）：把拼单当"**拼量撮合 + 线下成交**"，先做"**拼车物流**"和"**现货拼量撮合**"两个不依赖资金的形态；用信用分+二次确认+实名门槛替代定金；预售/钢厂直发凑量等待资金接入后（阶段 C）再上。
- 履约/付款全走线下，平台不代收货款；担保支付/定金锁价/自动退款属资金接入后目标态。
- 验证指标：帮卖成交 GMV、佣金结算额、拼单成团率、拼单 GMV、获客成本(CAC)。

> 多级分销、钢厂直发、预售等高风险/高复杂度形态放到本阶段后期，且分销上线前必须过法务评审。

### 阶段 3 · 平台调度层（活动 + 成长 + 数据）
**目标：让平台能"导演"裂变节奏，提升留存与 LTV。**

- 任务中心 + 积分商城 + 成长等级/勋章。
- 邀请有礼（阶梯、双向、防刷）。
- 排行榜 + 战队 PK。
- 节点大促 + 活动中台（配置化活动模板）。
- 商家自助营销工作台（呼应"让商家自主裂变"）。
- 全局数据看板（K 因子、各玩法贡献、CAC、漏斗）。

### 阶段 4 · 持续优化
- 归因规则精调、激励 ROI 优化、风控模型迭代、AB 实验体系、个性化推荐分发。

## 2. 北极星指标与关键指标

### 北极星指标（建议）
> **"通过裂变带来的、有效的采购/销售线索数"**（或进一步：由裂变带来的成交 GMV）。
> 它同时承载你的两个核心诉求：推广引流 + 获客（线索）。

### 分层指标（AARRR + 裂变）
| 层 | 指标 |
|----|------|
| 拉新 Acquisition | 新增注册/认证、各玩法拉新占比、CAC（获客成本） |
| 激活 Activation | 新用户完成首个有效行为率（认证/首单/首次帮卖） |
| 留存 Retention | 次日/7日/30日留存、行情日活 |
| 收入 Revenue | 帮卖佣金额、拼单 GMV、平台抽佣、商家付费 |
| 裂变 Referral | **K 因子**、分享率、分享→留资转化率、邀请有效激活率、裂变层级深度 |
| 线索质量 | 线索数、线索→报价→成交转化、线索评分分布 |

### 裂变健康度
- **K 因子 = 邀请数 × 邀请转化率**；目标在高动机玩法（拼单/帮卖/解锁）局部 >1。
- **病毒循环时间**：从一次分享到带来的新用户再次分享的平均时长，越短越好。
- **激励 ROI = 裂变带来的价值 / 激励成本**；持续监控，防止"发钱买虚假增长"。

## 3. 风控与合规检查清单（上线前必过）

- [ ] 邀请/解锁奖励仅在被带用户"认证 + 有效行为"后发放。
- [ ] 设备指纹 + 关系图谱识别小号/羊毛团伙。
- [ ] 佣金成交/回款后结算，异常交易（自买自卖/价格异常/关联账户）拦截。
- [ ] 抽奖优先于直接发现金；奖池/积分发行设预算熔断。
- [ ] **多级分销层级与计酬合规（法务评审），佣金挂钩真实交易，不为拉人头计酬**。
- [ ] 拼单走担保交易/资金托管；定金、违约金、磅差、退换规则清晰。
- [ ] 资源/行情真实性审核，资金/税务/发票合规。
- [ ] 个人信息脱敏、最小授权、防线索倒卖与爬取。

## 4. 给老板的"先做什么"一句话

> **先花力气把"追踪归因 + 激励结算"这套地基做扎实，再用"行情海报"这个零成本高频内容点第一把火验证模型；火着了，立刻上"资源帮卖 + 拼单"把流量变成成交和线索；最后用"任务积分 + 大促 + 商家营销工作台"把整盘棋的节奏掌控在平台手里。**
