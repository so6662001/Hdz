# 钢铁贸易平台 · 裂变增长战略总览

> 角色视角：营销总裁 + 平台运营官
> 目标：帮企业（商家/卖家）**推广引流、获客（线索）**，让商家、卖家、平台三方都能**自发裂变**。
> 本文是整套方案的"地图"，各玩法的详细设计见同目录下的分篇文档。

---

## 1. 先想清楚：B2B 钢贸的裂变和电商裂变不一样

很多平台直接照搬拼多多/社交电商的裂变（砍一刀、发红包拉人），在钢贸行业会"水土不服"。原因：

| 维度 | 消费电商 | 钢贸 B2B |
|------|---------|---------|
| 客单价 | 几十~几百元 | 几万~几百万元 |
| 决策 | 冲动、个人 | 理性、多人、要比价 |
| 频次 | 高频 | 中低频，但黏性强 |
| 关系 | 陌生人 | **强熟人圈层**（同行、上下游） |
| 传播动机 | 占便宜（红包） | **赚差价、攒人脉、立专业人设、降成本** |

**结论：钢贸裂变的"燃料"不是红包，而是三样东西——**

1. **信息差（行情）**：钢价天天波动，谁先知道、谁解读得好，谁就有话语权 → 传播行情=立人设。
2. **价格优势（资源 + 拼单）**：好货源、低价货稀缺；凑量能拿到钢厂直发价 → 传播资源/拉人拼单=有钱赚、有人情。
3. **关系变现（帮卖分销）**：圈里人脉本来就在帮人介绍买卖，平台把它产品化、可结算 → 介绍成交=拿佣金。

所有玩法都围绕这三点设计，红包/积分只是"润滑剂"，不是主引擎。

## 2. 三方角色与各自的裂变动机

平台要让**每一方都有"为自己而转发"的理由**，裂变才能自转。

### 卖家 / 商家（钢厂、钢贸商、代理商、加工厂）
- 诉求：把货卖掉、把品牌打出去、低成本获客（要线索）。
- 给他们的武器：**一键生成带自己品牌的资源海报/行情海报/微名片**，转发即获客；**招募帮卖分销员**把员工和圈子变成销售团队；**发起拼单**清库存、冲量。
- 裂变本质：商家转发是为了**自己的生意**，平台只需把"转发→留资→成交"的链路和归因做顺。

### 买家 / 采购方（终端工厂、加工厂、小钢贸、采购商）
- 诉求：买到便宜的、靠谱的货；省运费；少跑腿。
- 给他们的武器：**拼单凑量拿低价**（拉人越多越便宜）、**行情竞猜/订阅**（拉人解锁）、**求购悬赏**（发动人脉帮找货）。
- 裂变本质：买家拉人是因为**拉人能让自己更便宜/更快买到**。

### 平台
- 诉求：GMV、活跃、沉淀线索池与数据、形成网络效应。
- 给自己的武器：**任务/积分成长体系、节点大促、排行榜战队 PK、邀请有礼**，把三方的自发行为"调度"到平台想要的节奏上。
- 裂变本质：平台做"活动外壳 + 激励引擎 + 数据中台"，**不亲自下场拉人，而是让商家和买家替平台拉人**。

## 3. 增长飞轮（裂变怎么自转）

```
                 ┌───────────────────────────────────────┐
                 │                                         │
                 ▼                                         │
   [优质内容/资源/行情/拼单]  ──一键生成带追踪码的素材──►  [转发到 朋友圈/社群/微信好友]
                 ▲                                         │
                 │                                         ▼
        [激励:佣金/积分/低价/人设]  ◄──结算/解锁/排名──  [新用户点击→留资→成为线索/下单]
                 ▲                                         │
                 │                                         ▼
                 └──────  新用户也变成传播者（K因子>1）  ──┘
```

- **核心指标：K 因子（病毒系数）= 每个用户平均带来的新激活用户数。** K>1 即自增长。
- 钢贸现实里 K 很难全局 >1，所以策略是：**在"高动机场景"（拼单、帮卖、行情订阅）局部做到 K>1，用平台活动周期性点火。**

## 5. 落地节奏（建议）

详见 [`07-研发-技术架构与数据模型.md`](./07-研发-技术架构与数据模型.md) 和 [`08-落地-MVP路线图与运营指标.md`](./08-落地-MVP路线图与运营指标.md)。

- **第 1 阶段（地基 + 1 个爆点）**：追踪归因引擎 + 激励引擎 + 行情海报裂变（最易传播、最低成本起量）。
- **第 2 阶段（变现裂变）**：资源帮卖分销 + 拼单团购（直接拉 GMV 和线索）。
- **第 3 阶段（平台调度）**：任务成长体系 + 节点大促 + 排行榜战队 + 数据看板。

---

## 6. 一句话总结给老板听

> 我们不靠平台自己花钱拉人，而是**把行情变成商家的"人设海报"、把资源变成全员可分销的"提成商品"、把采购变成买家自发组织的"拼单团"**，再用积分任务和大促把这些行为调度起来；底层用一套"追踪归因 + 激励结算"引擎，保证**谁带来的客户算谁的、该给的钱自动结**，让商家、卖家、买家都为了自己的利益替平台做裂变。
