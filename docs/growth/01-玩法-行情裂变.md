# 玩法一 · 行情裂变

> 一句话：**把"每天看行情"这件刚需，变成用户主动转发、顺便给平台和商家拉客的入口。**
> 行情是钢贸唯一一个"每天都要看、看了还想转、转了能立人设"的内容，是裂变的最佳点火点。

---

## 1. 为什么行情最适合做裂变

- **高频刚需**：钢价天天波动，钢贸圈每天早上第一件事就是看行情、问价。
- **天然有转发动机**：在群里第一个甩出今日行情、还带点评的人，会被默认为"懂行的人"——**转发行情=免费立专业人设**。
- **零成本、低风险**：不像红包要花钱，行情内容平台本来就有，边际成本几乎为零。
- **承接力强**：每一次行情转发都可以挂上"商家名片 + 资源入口 + 留资按钮"，把围观流量变成线索。

---

## 2. 子玩法清单

### 2.1 个人 IP 行情海报（主力，必做）
**用户/商家一键生成"带自己名字、头像、公司、电话、二维码"的每日行情海报**，转发到朋友圈/社群。

- 内容模板：今日螺纹/线材/热卷/冷卷等主流品种价格 + 涨跌 + 一句话点评（平台自动生成 or 商家自填）。
- 海报右下角固定挂：**商家微名片二维码（带专属追踪码）**。别人扫码 = 这个商家的线索。
- 多套模板（简约风/喜报风/早报风/收盘风），换皮即可天天发不腻。
- **运营钩子**：连续 N 天分享行情海报 → 解锁"行情达人"勋章 + 积分；勋章展示在微名片上，强化人设。

> 这一招把"平台行情"变成了"商家的获客工具"，商家有强烈动机每天替平台传播。

### 2.2 行情订阅解锁（拉新解锁高级行情）
基础行情免费看；**深度内容（区域价差、钢厂调价、库存数据、明日预判、品种专题）需要"解锁"**。

- 解锁方式（任选）：邀请 N 位新用户 / 完成分享任务 / 用积分兑换 / 成为会员。
- 邀请解锁是核心裂变点：**"再邀 2 位同行，解锁本周钢厂调价汇总"**。
- 被邀请人进来也看到同样的解锁诱惑 → 链式裂变。

### 2.3 行情竞猜 / 涨跌预测（互动 + 拉票裂变）
**"猜明日螺纹钢涨还是跌"**，猜中得积分/红包/抽奖资格。

- 拉票/组队加成：拉好友一起猜，命中后双方都加奖励；分享战绩海报（"我已连续 7 天猜中行情"）。
- 周榜/月榜：预测准确率排行榜，上榜者获"行情先知"称号 → 又是人设，又能导流到其主页/资源。
- 低成本、强互动、可天天玩，是维持日活和裂变频次的"日抛型"玩法。

### 2.4 社群行情分发 + 群专属码（B2B 关键）
钢贸生意大量在微信群里。提供**"一键转发到社群"且每个群/每次分发带专属追踪码**的能力。

- 商家把行情卡片转到自己的客户群，群里谁点击/留资，**归因到该商家**。
- 群内"接龙问价"：行情卡片下挂"报价接龙"，群友点"我要这个价"即留资，商家后台收集需求。
- 平台可统计"哪个群最活跃、哪条行情转发最多"，反哺内容选题。

### 2.5 行情订阅机器人 / 服务号推送（留存 + 复发）
- 用户订阅后，每天定时推送行情（公众号/企微/短信），推送内容内置分享按钮 → 推送即可能再裂变。
- 这是把一次性裂变流量"留下来反复触达"的承接器。

## 3. 用户旅程示例

```
钢贸商老王 早上打开平台
   → 看到"今日行情海报已生成（你的专属版）"
   → 一键转发到 3 个客户群 + 朋友圈（海报带老王名片二维码 + 追踪码）
   → 群友老李扫码看更多 → 想看"本周钢厂调价" → 提示"邀2位同行解锁"
   → 老李邀请了 2 个采购朋友 → 解锁成功，3 人都成为平台新用户
   → 这 3 个新用户，因为是从老王的码进来的，留资后线索归给老王
   → 老王收到"您通过行情分享获得 3 条新线索"通知 → 更有动力天天发
```

K 因子在这个闭环里来自两处：老王的转发（1→N）+ 老李的解锁邀请（再 1→2）。

## 4. 激励设计（接激励引擎，见 `05`）

| 行为 | 即时激励 | 长期激励 |
|------|---------|---------|
| 生成并分享行情海报 | 积分 +X | 连续打卡勋章、达人等级 |
| 通过我的码带来新用户 | 积分/红包 | 线索归属、转化提成（接帮卖分销） |
| 行情竞猜命中 | 积分/抽奖 | 准确率排行榜、称号 |
| 邀请解锁高级行情 | 解锁内容本身 | 会员成长值 |

> 原则：**奖励"带来真实新用户/线索"，而不是奖励"点击/转发次数"**，否则会被刷。

---

## 5. 防作弊要点（详见风控章节）

- 邀请解锁需"新用户完成实名/企业认证 + 有效行为"才计数，防小号。
- 同设备/同 IP/同手机号段批量注册识别。
- 竞猜奖励设上限、抽奖代替直接发钱，降低薅羊毛收益。
- 行情数据本身要保证权威准确（错的行情会反噬信任），需有数据源与审核流程。

---

## 6. 研发拆解（给技术）

- **行情数据服务**：行情录入/对接数据源、品种与地区维度、历史曲线、调价/库存等深度数据分级（免费/解锁/会员）。
- **海报生成服务**：模板引擎（服务端渲染图片）+ 动态注入用户名片与追踪码（二维码生成）。建议异步生成 + CDN 缓存。
- **分享追踪**：每次"生成海报/转发"产出带 `spread_code` 的短链/二维码，接入归因引擎（见 `06`）。
- **解锁与权限**：内容分级 + 解锁条件判定（邀请数/积分/会员），接激励引擎。
- **竞猜服务**：开奖（依赖次日真实行情）、积分结算、排行榜。
- 数据模型与 API 见 [`07-研发-技术架构与数据模型.md`](./07-研发-技术架构与数据模型.md)。

---

## 7. 为什么把它列为第一个开发的玩法

- 成本最低（内容现成）、风险最低（不直接发钱）、最易起量（人人每天都看行情）。
- 它会顺手把"追踪归因引擎 + 海报生成 + 激励积分"这三块地基跑通，为后面的帮卖/拼单铺路。
