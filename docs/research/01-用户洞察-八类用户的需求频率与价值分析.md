# 用户洞察 · 八类用户的需求频率、必须度与现状替代分析

> 视角：资深市场调研 / 用户洞察（钢贸流通领域）
> 前提：**先不论平台有什么能力**，只回答一个问题——如果这些人来用一个"钢铁现货资源平台"，他们各自需要什么价值？这些价值对他们是刚需还是可选？他们现在是怎么解决的、平台凭什么替代？
> 分析对象（8 类）：终端用料企业、工程项目购料方、钢材门店、经常采购钢材的个人、小贸易商、小批发/小门店、中型批发商、大批发商。
> 用法：这是做产品优先级、招商话术、运营分层之前的"地基文档"。结论见第 10 节，赶时间先看第 0 节和第 10 节。

---

## 0. 一页结论

1. **八类人其实只有四种"角色"**：纯买方（终端、工程、个人）、纯卖方（大批发）、买卖双身份（小贸易商、小批发、门店、中批发）、以及每类里真正在操作电脑/手机的"人"（采购员、材料员、业务员、老板娘）。**买卖双身份的中小钢贸商是钢贸流通的"中枢"，也是唯一会每天打开平台的人。**
2. **所有人的高频需求只有三件事：看价（行情）、找货 / 找人（匹配）、报价 / 传播（卖方）。** 其余需求（结算、开票、物流、融资、招标）频率低或平台无法介入。
3. **"必须"的只有两处**：小贸易商的"找货 + 找客"是生死线；中小批发商的"低成本获客 + 库存曝光"是增量线。其余群体对平台都是"重要但可替代"或"偶尔用一次"。
4. **当前替代物是微信 + 电话 + 熟人 + 钢材市场物理聚集 + 我的钢铁（Mysteel）**，不是任何一个竞品平台。微信解决了"快、熟、可信"，没解决"全、准、新鲜、可沉淀、可归因"。平台唯一的机会是**做微信做不了的那部分，并把结果送回微信**，而不是让人离开微信。
5. **频率与价值倒挂**：高频的看行情价值低、无法收费；低频的紧急找货 / 找到新客户价值极高。策略必然是"**高频养习惯，低频赚钱**"。
6. **买卖双方的核心诉求天然冲突**：买方要透明比价，卖方（尤其中大批发）拒绝公开价格。平台不能两头讨好，必须选边——**以中小卖方为核心用户，买方是给卖方的"交付物"（线索）**，这与平台"不做线上交易、以线索为中心"的定位一致。

## 1. 分析框架

### 1.1 频率定义
| 等级 | 定义 | 典型 |
|------|------|------|
| **高频** | 每天到每周多次，已成为工作流的一部分 | 早上看价、发库存表、群里问货 |
| **中频** | 每周到每月一次，事件驱动但规律出现 | 月度采购、补库、对账、找新供应商 |
| **低频** | 每季到每年一次，或突发事件触发 | 招标入库、冬储、锁价、紧急缺料 |

### 1.2 必须度定义
| 符号 | 含义 | 判断标准 |
|------|------|---------|
| ★★★ 刚需 | 不解决就不会用、或解决了就离不开 | 直接关系到"有没有生意 / 有没有货" |
| ★★ 重要 | 明显省时间或多赚钱，会主动回来用 | 效率提升 30% 以上或带来增量收入 |
| ★ 可选 | 有就顺手用，没有也无所谓 | 现有方式已够用 |
| ○ 不需要 / 抵触 | 不需要，或与自身利益冲突 | 例如中大批发商不愿公开价格 |

### 1.3 "与当前方式的关系"定义
- **替代**：平台方式全面优于现状，可以取代（少见）。
- **补充**：现状仍是主路径，平台在特定场景（更广、更快、更准）补位（多数情况）。
- **嵌入**：平台不改变现状路径，而是成为现状路径中的一个工具（例如生成海报发到微信）。
- **无法介入**：环节被熟人关系、线下流程或大公司系统锁定。

### 1.4 一个必须先建立的认知：钢贸的"当前方式"到底是什么

| 环节 | 现状主路径 | 现状为什么高效 | 现状的缺口 |
|------|-----------|--------------|-----------|
| 看行情 | 我的钢铁 / 钢银 / 西本 / 兰格 APP、期货盘面（rb / hc）、群里转的"早报"截图 | 权威、有均价可当依据 | 只是"市场价"，不是"我今天能买到的价"；解读能力两极分化 |
| 找货 | 微信群（每人几十到几百个群）、朋友圈刷库存表、打熟人电话、去钢材市场转 | 秒回、熟人可信、顺带聊关系 | 群信息过时、找不到、没沉淀；生人报价不敢信；跨区域几乎盲 |
| 找客户 | 老客户复购、熟人介绍、业务员跑工地 / 跑门店、朋友圈每日发报价、58 / 百度 / 1688 挂广告 | 老客户占 70%~90% 生意 | 新客获取极贵且慢，年轻业务员没人脉；朋友圈发了不知道谁看了 |
| 成交 / 履约 | 电话敲定 → 微信确认 → 开提单 / 仓单 → 仓库出库 → 过磅 → 物流 → 对账开票 | 流程成熟，各方角色清晰 | 全线下，没有任何数据留在任何平台上 |
| 结算 | 现款现货（散客 / 门店）、账期 + 商票 / 银承（工程、终端）、托盘垫资 | 关系决定账期 | 应收风险高，与平台无关 |

> **结论：现状不是"落后"，而是"高效但封闭"。** 用户不是缺工具，是缺"更广的视野 + 可信的生人 + 可沉淀的结果"。平台价值必须落在这三点上。

## 2. 终端用料企业

### 2.1 画像
- 谁：机械制造、汽配、钢结构加工厂、家电、五金、金属制品、造船、压力容器等；规模从几十人到上千人。
- 买什么：板材（热轧 / 冷轧 / 镀锌 / 中厚板）、型材、管材、优特钢，**对材质、规格、定尺、质保书、加工（开平 / 纵剪 / 切割）要求高**。
- 决策链：采购员执行 → 采购经理 / 老板批 → 品质 / 生产提要求 → 财务管账期。**采购员是使用者，老板是决策者，两者利益并不完全一致。**
- 采购方式：固定 2~5 家供应商（多为中型批发商或钢厂代理），年度框架 + 月度 / 周度订单；大厂走 SRM / 招标平台。

### 2.2 当前怎么干
- 行情：采购员每天看我的钢铁 / 期货，用来判断"这周买还是下周买"，以及向老板证明"我买的价格不高于市场均价"。
- 找货：常规规格问固定供应商；**紧急缺料 / 非常规规格**时靠供应商帮找、群里发、打电话。
- 比价：每次采购走 2~3 家询价流程（合规要求），但实际上多数是"陪标"。
- 履约：到货验收、质保书、对账、开票，走自己 ERP。

### 2.3 核心痛点
1. **价格依据**：老板 / 财务质疑"为什么这个价"，采购员需要第三方均价背书。
2. **紧急缺料**：常规供应商无货时，找一个能当天 / 次日到货的供应商极难，往往加价 5%~10% 从二级市场拿。
3. **非常规规格 / 材质**：小众规格（如特定厚度冷轧、特殊材质）全网找不到。
4. **供应商风险**：单一依赖，供应商出问题即断供；想找备胎又不知道谁靠谱。
5. **加工配送**：需要"带加工的货"，纯卖钢不满足。

### 2.4 需求分层

| 频率 | 需求 | 具体场景 | 必须度 | 当前方式 | 平台相对现状 |
|------|------|---------|-------|---------|-------------|
| 高频 | 行情跟踪与价格依据 | 每日看价、判断采购时机；月度定价谈判时拿均价当依据 | ★★ | Mysteel 等付费行情 | **补充**：平台若有"本地可成交价"比"全国均价"更有说服力；但难以替代权威均价 |
| 高频 | 到货 / 对账 / 质保书 | 每批货核对 | ○ | 供应商 + 自家 ERP | 无法介入 |
| 中频 | 询价比价（合规三家） | 每次采购 | ★★ | 微信 / 电话固定供应商 | **补充**：一次询多家、留痕；但采购员并不真想换供应商 |
| 中频 | 月度采购下单、账期结算 | 每月 | ○ | 线下合同 | 无法介入 |
| 中频 | 寻找备用 / 新供应商 | 每季度或供应商出问题时 | ★★ | 同行介绍、展会、搜索 | **补充→潜在替代**：结构化的"谁有什么货、在哪、多久更新"是现状完全没有的 |
| 低频 | 紧急缺料找货 | 一年几次，但每次损失巨大（停线） | ★★★（发生时） | 群里喊、供应商帮找、加价买 | **替代机会最大**：按规格 × 区域 × 库存搜索，是微信做不到的 |
| 低频 | 非常规规格 / 材质找货 | 新产品 / 新订单 | ★★ | 靠供应商人脉 | 补充 |
| 低频 | 年度招标 / 供应商准入 | 每年 | ★ | 招标平台、内部流程 | 大厂无法介入；中小厂可提供候选名单 |
| 低频 | 锁价 / 冬储 / 套保决策 | 每年 | ★ | 老板拍脑袋 + 行情研判 | 补充（行情解读内容） |

### 2.5 结论
- **依赖类型：偶用型，"救火队"**。日常不会打开，缺料时会想起来。要让他们在缺料那一刻想起平台，前提是平时用"行情 + 价格依据"维持弱连接。
- **必须吗？不必须。** 现有供应商体系够用；平台是备份和放大器。
- **关键洞察**：采购员的个人利益（关系、回扣、稽核风险）决定他不会主动把采购搬到任何平台；**能打动他的是"帮他向老板交差"（价格依据）和"帮他救火"（紧急找货）**，而不是"帮公司省钱"。
- **切换触发点**：一次成功的紧急找货。

## 3. 工程项目购料方

### 3.1 画像
- 谁：总包 / 分包的项目部材料员、公司物资部集采人员、劳务分包 / 二级承包的包工头（大量）。
- 买什么：螺纹钢、盘螺、线材、型钢、钢管（脚手架 / 支撑）、钢板（临建 / 铺路）、预埋件。**品牌受甲方 / 监理限制**（指定品牌清单），批量大、按进度分批、地域性极强（就近仓库）。
- 决策链：项目部提需求 → 公司物资部询价定供应商 → 项目经理 / 成本部批 → 财务按月结算。央企国企走自有集采平台（如云筑网、鲁班、中交电商等）。
- 特殊性：**账期长（3~6 个月，商票 / 银承普遍），供应商必须能垫资**；月度结算按"信息价 / 市场价"调差，因此对**权威行情有制度性需求**。

### 3.2 当前怎么干
- 项目启动时：公司供应商库 + 熟人 + 本地钢材市场跑一圈，选 2~3 家。
- 日常：材料员根据施工进度提计划，供应商送货到工地（卸车时间窗口、夜间限行、过磅、见证取样复试）。
- 紧急补料：常见（进度突变、变更、返工），当天要货，现有供应商无货就满市场打电话。
- 结算：按月对账、调差、开票、挂账。

### 3.3 核心痛点
1. **垫资 + 就近 + 品牌合规**三重约束，符合条件的供应商很少。
2. 紧急补料"今天要、要这个品牌、要送到工地"，找货困难。
3. 材料员需要行情依据做**调差和成本汇报**，但拿到的是全国 / 省会价，与工地所在地不符。
4. 供应商送货可靠性（尺寸、磅差、质保书齐全）直接影响验收。
5. 项目结束供应商关系就断，下一个项目换城市重新找。

### 3.4 需求分层

| 频率 | 需求 | 具体场景 | 必须度 | 当前方式 | 平台相对现状 |
|------|------|---------|-------|---------|-------------|
| 高频 | 到货跟踪、验收、质保书 | 每车 | ○ | 供应商 + 项目系统 | 无法介入 |
| 高频（材料员） | 本地行情（调差 / 报计划） | 每周 | ★★ | 造价信息价 + Mysteel + 群 | **补充**：区域级"可成交价"对调差谈判有价值 |
| 中频 | 月度采购计划与询价 | 每月 | ★★ | 微信 / 电话 2~3 家 | **补充**：能一次覆盖更多本地有货供应商 |
| 中频 | 紧急补料就近找货 | 每月至少一次 | ★★★（发生时） | 电话轰炸 | **替代机会大**：按"品牌 × 规格 × 距离工地 × 今日可提"搜索 |
| 中频 | 月度对账、调差、结算 | 每月 | ○ | 线下 | 无法介入 |
| 低频 | 项目启动时供应商筛选 | 每个项目 | ★★★ | 公司库 + 熟人 + 跑市场 | **补充→替代**：换城市时现状失效，平台价值最大 |
| 低频 | 大宗锁价 / 集采招标 | 每年 / 每项目 | ★ | 集采平台 | 央企国企无法介入，民企中小总包可提供候选 |
| 低频 | 找有垫资能力的供应商 | 项目启动 | ★★★ | 熟人 | 补充（平台能标注"接受账期 / 商票"是差异化信息） |

### 3.5 结论
- **依赖类型：项目周期型。** 项目启动和紧急补料两个时刻需求强烈，其余时间沉默。
- **必须吗？对材料员不必须，对"到新城市开项目"这一时刻很必须。**
- **关键洞察**：工程购料的核心筛选条件不是价格，是"**能不能垫资、能不能送到、品牌对不对**"。任何只展示价格的信息对他们价值有限；"接受账期 / 商票""送货到工地""在售品牌清单"这类**交易条件信息**才是他们真正想看的。
- **包工头子群体**（劳务 / 二级承包）行为更像"经常采购的个人"（见第 5 节），量小、现款、价格敏感、就近门店。

## 4. 钢材门店（零售型）

### 4.1 画像
- 谁：位于建材市场 / 钢材市场 / 县城街边的零售门店，多为夫妻店或 2~5 人，品种杂（方管、角钢、槽钢、螺纹、钢板零剪、镀锌管、铁艺配件），有几十到几百吨库存，自带零剪 / 简单加工。
- 客户：装修队、铁艺 / 门窗 / 护栏师傅、小加工作坊、农村自建房、维修工、周边小工程。
- 上游：小批发商 / 中批发商，或大市场里的批发户。
- 特征：**批零兼营，既是买方（补货）又是卖方（零售）**；老板即业务员即采购即会计；靠位置和口碑吃饭。

### 4.2 当前怎么干
- 上游补货：每天早上看上游发的库存表 / 报价（微信），缺什么打电话让送；价格波动大时观望或多进。
- 零售获客：自然客流（位置）、老客户、抖音 / 快手 / 微信视频号发短视频、58 / 百度 / 美团（少数）、亲戚朋友介绍。
- 报价：随行就市，上游价 + 固定加价，散客口头报。
- 记账：手工账本 / 简易进销存 / 微信备注，赊账普遍。

### 4.3 核心痛点
1. **补货价格是否合理**：不知道自己拿到的是不是最低价，被上游"吃差价"。
2. **零售客流不稳定**：淡旺季明显，位置差的店没有生意。
3. **缺规格**：客户要的品种自己没有，去隔壁调货，利润被分走。
4. **赊账与坏账**。
5. **线上不会做**：想在抖音 / 本地生活获客，不会拍不会投。

### 4.4 需求分层

| 频率 | 需求 | 具体场景 | 必须度 | 当前方式 | 平台相对现状 |
|------|------|---------|-------|---------|-------------|
| 高频 | 上游价格与行情 | 每天早上决定补不补、报多少 | ★★★ | 上游微信报价 + 群 | **补充→部分替代**：一次看多家上游报价，打破单一上游信息不对称 |
| 高频 | 零售客流 / 询价线索 | 每天 | ★★★ | 位置、抖音、老客 | **补充**：本地买家搜索"附近有货门店"是现状缺的；但线索量能否达到抖音水平是关键 |
| 高频 | 记账 / 赊账 / 收款 | 每天 | ★ | 账本 / 小程序 | 可选（不核心，市面工具多） |
| 中频 | 补货找货（缺规格调货） | 每周 | ★★ | 隔壁店、上游 | 补充：跨店调货信息 |
| 中频 | 找新上游 / 比上游 | 每月或价格异常时 | ★★ | 熟人 | 补充 |
| 中频 | 对外传播（朋友圈报价 / 短视频） | 每周 | ★★ | 自己手写 / 拍 | **嵌入**：一键生成带门店信息的报价图 / 海报是顺手工具 |
| 低频 | 冬储 / 囤货决策 | 每年 | ★ | 老板判断 | 补充（行情解读） |
| 低频 | 开票 / 税务 | 偶尔 | ○ | 代账 | 无法介入 |

### 4.5 结论
- **依赖类型：习惯型（若有价值）。** 门店老板每天开门第一件事是看价，若平台成为"看价 + 看谁来问"的入口，会成高频。
- **必须吗？"上游价格透明 + 本地客流"是刚需，但平台是否能满足取决于供给密度和买家密度，不是需求侧问题。**
- **关键洞察**：门店是**最容易被"上游价格透明"打动的卖方**，因为他们在上游面前是弱势买方；同时他们对下游散客又希望不透明。**门店愿意用平台比上游价，但不希望散客用平台比自己的价**——这是设计"谁能看到什么价格"时必须处理的矛盾。
- **切换触发点**：发现平台上有比自己现有上游更便宜的货；或平台带来了第一个真实散客。

## 5. 经常采购钢材的个人

### 5.1 画像
- 谁：小土建 / 装修包工头、铁艺 / 门窗 / 护栏 / 雨棚师傅、农村自建房业主、个体加工作坊主（无公司）、设备维修 / 农机 / 养殖设施搭建者。
- 买什么：螺纹钢、方管、角钢、槽钢、镀锌管、钢板零剪、彩钢；单次几百公斤到几十吨；**现款、要送货、常需零剪 / 简单加工**。
- 决策：自己拍板，价格敏感，**最怕被坑**（地条钢、非标短尺、缺斤少两、磅差、以次充好）。
- 频率：包工头 / 师傅每周到每月买；自建房业主一生几次。

### 5.2 当前怎么干
- 找店：熟悉的门店老板（长期关系）、去建材市场转、百度 / 抖音 / 高德搜"附近钢材"、亲友介绍。
- 比价：问 2~3 家，电话或到店。
- 送货：门店送 / 自己找车（货拉拉）。
- 质量判断：看品牌钢印、听老板说、靠信任。

### 5.3 核心痛点
1. **不知道合理价**：信息完全不对称，买贵了也不知道。
2. **怕假货 / 非标 / 短尺**。
3. **小量没人愿意接、加工没人愿意做**。
4. **就近 + 送货 + 时间确定**比价格更重要（工期）。
5. 找不到"靠谱的人"，每换一个地方施工都要重新找。

### 5.4 需求分层

| 频率 | 需求 | 具体场景 | 必须度 | 当前方式 | 平台相对现状 |
|------|------|---------|-------|---------|-------------|
| 中频 | 问价 / 比价 | 每次采购前 | ★★★ | 问 2~3 家熟店 | **补充→替代**：一次看多家本地零售价 + 参考价"不被坑"是核心价值 |
| 中频 | 找就近门店 / 有货 / 可零剪 / 可送 | 每次采购 | ★★★ | 熟店、地图搜 | **替代机会**：地图 + 品类 + 零剪 + 送货筛选是现状缺的 |
| 中频 | 送货 / 找车 | 每次 | ★ | 门店送、货拉拉 | 无需介入 |
| 低频 | 大单（自建房 / 小工程整批） | 偶尔 | ★★ | 熟人介绍 | 补充 |
| 低频 | 质量 / 防坑知识 | 偶尔 | ★★ | 靠经验 | 补充（内容） |
| 低频 | 二手 / 旧钢材买卖 | 偶尔 | ★ | 废品站 / 熟人 | 可选 |

### 5.5 结论
- **依赖类型：工具型、低留存。** 用完即走，单个用户 LTV 低。
- **必须吗？对个人不必须**（现有方式够用），但**对门店和小批发商而言，这群人是最想要的"线索"**。
- **关键洞察**：个人买家的价值不在自身，而在于**作为卖方线索的供给**。平台要的不是"留住个人"，而是"每个个人来的时候能精准分给一个门店并被门店记住"。获取个人的渠道不在平台内，在抖音 / 地图 / 搜索——即平台需要把门店"送"到个人在的地方（这与门店"不会做线上"的痛点是同一件事的两面）。
- **风险**：个人对价格透明的需求与门店对散客不透明的需求直接冲突，需要用"参考价区间 + 门店实报"而非公开挂价来平衡。

## 6. 卖钢材的小贸易商（无库存 / 少库存）

### 6.1 画像
- 谁：1~3 人的贸易公司或个体，**基本无库存**，靠"上游有货 + 下游有需求"做居间 / 背靠背 / 代采，赊销靠自有资金周转；很多是从大批发商出来的业务员单干。
- 生存逻辑：**信息差 + 人脉 + 服务**。上游是中大批发商 / 钢厂代理，下游是工程、小加工厂、门店、终端。
- 典型一天：早上看盘看早报 → 收几十份上游库存表 → 整理成自己的报价发朋友圈 / 群 → 接客户询价 → 满市场找货 → 敲定 → 协调提货物流 → 催款。
- 生死线：**能不能找到货、能不能找到客**。两者缺一即无收入。

### 6.2 当前怎么干
- 找货：100~300 个微信群、朋友圈刷屏、上游业务员私聊、打电话、去市场。
- 找客：老客户、熟人介绍、朋友圈人设经营（每天发行情 + 报价 + 生活）、抖音 / 快手（少数做得好的）、扫工地。
- 报价工具：手机备忘录、Excel 截图、群里转发、简单报价单小程序。
- 信任建立：靠"共同好友""某某大公司出来的""见过面"。

### 6.3 核心痛点
1. **找货效率低**：翻几百个群、打几十个电话，找的是"今天在哪个仓库、什么价、能不能提"。
2. **新客获取靠命**：朋友圈发了没人看，不知道谁看了，年轻人没人脉。
3. **信任门槛高**：生人客户不敢跟"皮包公司"做，需要"身份背书"。
4. **报价被比价 / 被跳单**：上游直接接触自己的客户。
5. **资金**：垫资能力弱，客户账期一长就做不了。
6. **信息过载 + 不结构化**：所有信息都在微信里，找不到、不沉淀。

### 6.4 需求分层

| 频率 | 需求 | 具体场景 | 必须度 | 当前方式 | 平台相对现状 |
|------|------|---------|-------|---------|-------------|
| 高频 | 找货（谁有 / 在哪 / 多少钱 / 能提吗） | 每天多次，每单必做 | ★★★ | 群 + 电话 + 朋友圈 | **补充→替代**：结构化、可搜索、带新鲜度的资源池是微信做不到的；替代的前提是密度和新鲜度 |
| 高频 | 行情与早报 | 每天早上 | ★★★ | Mysteel + 群转发 | **嵌入**：他们不仅要看，还要"转发出去立人设"，行情内容要可传播 |
| 高频 | 对外报价 / 朋友圈人设 | 每天 | ★★★ | 手工整理、截图 | **嵌入→替代**：带追踪的报价单 / 海报 / 名片，知道谁看了、谁点了，是"找客"的抓手 |
| 高频 | 接询价、跟客户 | 每天 | ★★ | 微信私聊 | 补充（线索归集与提醒） |
| 中频 | 获得新客户线索 | 每周 | ★★★ | 熟人、朋友圈、扫工地 | **替代机会最大**：这是他们愿意付费的唯一一件事 |
| 中频 | 找新上游 / 跨区域找货 | 每周 | ★★ | 群 | 补充 |
| 中频 | 身份 / 信用背书 | 每个新客户 | ★★ | 靠介绍人 | **补充**：平台认证身份、从业年限、同行背书，是现状缺的 |
| 中频 | 物流找车 / 提货协调 | 每单 | ★ | 货拉拉 / 专线 / 熟车队 | 无需介入 |
| 低频 | 垫资 / 托盘 | 大单时 | ★★ | 找托盘公司 | 平台不做交易则无法介入，可做信息对接 |
| 低频 | 开票 / 走公司 | 每单 | ○ | 自己公司或挂靠 | 无法介入 |

### 6.5 结论
- **依赖类型：刚需型、每日打开。** 只要平台在"找货"或"找客"任一项上明显优于微信，他们会成为最活跃、最忠诚、也最能带来内容（报价、资源转发）的用户。
- **必须吗？找货 + 找客是必须，行情 + 报价工具是嵌入型刚需。** 这是八类人中唯一"平台价值 = 生存价值"的群体。
- **关键洞察**：小贸易商是**平台的"内容生产者 + 传播节点 + 需求发起者"三合一**。他们每天转发几十条信息到几百个群，是天然的裂变节点；他们的资源多是转发上游的，因此平台上的"资源"很大比例会来自他们的二次搬运——这带来**信息真伪与新鲜度问题**，需要"一手 / 二手"标识。
- **风险**：他们最怕被"去中间化"——如果平台让终端直接找到大批发商，他们会抵制甚至制造垃圾信息。平台需要明确"保护中间商"的规则（例如买方不能直接看到货主是谁、线索归属明确）。
- **切换触发点**：在平台上找到一单微信里找不到的货；或通过平台海报 / 名片接到第一个生客。

## 7. 卖钢材的小批发 / 小门店（批零兼营，有库存）

### 7.1 画像
- 谁：钢材市场内的批发户，3~10 人，几百到两三千吨库存，主营 1~2 个品类（如建材类螺纹盘螺，或型材，或管材，或板材），有固定仓库 / 堆场，下游是门店、小工程、加工户、小贸易商；上游是中大批发商或 2~3 家钢厂的二级代理。
- 与"钢材门店"的区别：更批发、量更大、客户以 B 端为主、有业务员、更关注上游价格和库存周转；很多同时也做零售。
- 资金：几百万到两三千万流动资金，赊销压力大，价格波动直接影响库存盈亏。

### 7.2 当前怎么干
- 每天早上 8 点前：根据盘面和上游调价出自己的报价，做库存表（Excel / 进销存导出 / 手写拍照）发到几十个群和朋友圈。
- 找客：业务员跑市场、跑工地、老客户维护；偶尔 58 / 百度 / 找钢网挂货。
- 补货：每周看上游价格与自己库存，判断补多少；价格看涨时多囤。
- 出货：接电话 → 开单 → 仓库出库过磅 → 客户自提或送货 → 收款 / 挂账。

### 7.3 核心痛点
1. **库存表发出去没反馈**：不知道谁看了、谁感兴趣，只能等电话。
2. **新客难**：市场内竞争同质化，价格战；业务员流失带走客户。
3. **库存与价格风险**：囤错了就亏，需要更好的行情判断。
4. **零售散客不会做线上**（与门店同）。
5. **下游赊账、坏账**。

### 7.4 需求分层

| 频率 | 需求 | 具体场景 | 必须度 | 当前方式 | 平台相对现状 |
|------|------|---------|-------|---------|-------------|
| 高频 | 行情 / 盘面 / 上游调价 | 每天早上定价 | ★★★ | Mysteel + 期货 + 上游通知 | 补充（区域化、可传播） |
| 高频 | 发布库存表 / 报价并传播 | 每天 | ★★★ | Excel 截图发群 | **嵌入→替代**：一次发布多端同步（群、朋友圈、平台页面），且有"谁看了"反馈，是显著升级 |
| 高频 | 接询价、报价、跟单 | 每天 | ★★ | 电话 / 微信 | 补充（线索归集） |
| 高频 | 出库 / 过磅 / 收款 | 每天 | ○ | 进销存 | 无法介入 |
| 中频 | 新客户线索（门店 / 工程 / 加工户） | 每周 | ★★★ | 业务员跑 | **替代机会大**：本地买方搜到"我"是核心增量 |
| 中频 | 上游比价、补货决策 | 每周 | ★★ | 2~3 家上游报价 | 补充 |
| 中频 | 清库存 / 处理尾货非标 | 每月 | ★★ | 群里甩卖 | 补充（专区曝光） |
| 中频 | 团队报价 / 客户归属管理 | 持续 | ★★ | 无 / 靠老板脑子 | **补充**：每个业务员一码、线索归属，解决"业务员走了客户跟走" |
| 低频 | 冬储 / 囤货判断 | 每年 | ★★ | 老板经验 | 补充（内容） |
| 低频 | 找新上游 / 拿代理 | 每年 | ★ | 关系 | 可选 |
| 低频 | 融资 / 托盘 / 保理 | 需要时 | ★ | 银行 / 托盘公司 | 无法介入 |

### 7.5 结论
- **依赖类型：习惯型 + 增量型。** 每天发库存表是既有习惯，只要平台把"发库存表"这一步接管并给出反馈，就成为每日必用；增量客户则决定他们是否愿意付费。
- **必须吗？"低成本获客 + 库存曝光"是刚需，"行情"是嵌入型刚需。**
- **关键洞察**：小批发商是**供给密度的主力**——他们有真实库存、每天更新、有动机曝光。平台早期"有货、有价、有人回"的地基主要靠他们。他们对"公开价格"的态度是**分层的**：对同行 / 散客不想公开，对潜在 B 端客户愿意公开。因此"价格对谁可见"必须可控。
- **切换触发点**：平台发布库存表比发群省事且能看到浏览 / 询价反馈；或第一次从平台接到陌生的工程 / 门店订单。

## 8. 卖钢材的中型批发商

### 8.1 画像
- 谁：10~50 人的钢贸公司，月销几千到两三万吨，1~3 家钢厂的协议户 / 区域代理，多品类，有自己仓库或长期租用仓库，有加工配送能力（部分），有 5~30 人销售团队，使用进销存 / ERP（钢银、自建、金蝶 / 用友类）。
- 下游：终端工厂、工程项目、小批发、门店、小贸易商；上游：钢厂 + 大批发商调剂。
- 资金与风险：大量资金压在库存和应收上，做托盘 / 赊销，关注期现套保。
- 决策：老板定策略与大客户，销售经理带团队，业务员日常报价跟单，财务管资金。

### 8.2 当前怎么干
- 行情：付费订阅 Mysteel / 钢银等，看期货盘面，参加钢厂订货会，内部每天早会定价。
- 销售：业务员各自维护客户群、发库存表；老板维护大客户与钢厂关系；招投标参与工程集采；找钢网等平台挂货（效果一般，且不愿公开低价）。
- 库存与提货：ERP 管库存，仓单 / 提单，加工配送。
- 团队管理：业绩考核、客户归属混乱、业务员流失带客户是长期顽疾。

### 8.3 核心痛点
1. **获客成本高且不可控**：新客户全靠业务员个人，团队能力参差。
2. **品牌 / 信誉建设无渠道**：想让市场知道"我是 XX 钢厂代理、我有货、我靠谱"，只能靠口碑。
3. **库存表传播效率低、无数据**：几十个业务员各发各的，没有统一出口和反馈。
4. **客户资产不在公司手里**（在业务员微信里）。
5. **价格策略两难**：想曝光又不想公开底价，怕同行看、怕大客户压价。
6. **应收与资金**。

### 8.4 需求分层

| 频率 | 需求 | 具体场景 | 必须度 | 当前方式 | 平台相对现状 |
|------|------|---------|-------|---------|-------------|
| 高频 | 行情 / 盘面 / 钢厂政策 | 每天早会 | ★★（已被满足） | 付费行情 + 钢厂 | 补充（很难替代 Mysteel） |
| 高频 | 团队统一发布库存 / 报价并传播 | 每天 | ★★★ | 各业务员自发 | **嵌入→替代**：公司统一发布、每人一码分发、可见"谁看了 / 谁问了"，是管理与营销双升级 |
| 高频 | 询价接入与线索分配 | 每天 | ★★ | 谁接到算谁的 | 补充（线索池 + 分配 + 归属） |
| 高频 | 出库 / 物流 / 加工排产 | 每天 | ○ | ERP | 无法介入 |
| 中频 | 新客户线索（终端 / 工程 / 门店） | 每周 | ★★★ | 业务员跑、招标 | **替代机会大**，且是最有付费能力的群体 |
| 中频 | 品牌 / 代理身份曝光 | 持续 | ★★ | 无 | **补充→替代**：认证代理、企业主页、内容输出，现状几乎为零 |
| 中频 | 钢厂订货 / 锁价 | 每月 | ○ | 钢厂系统 / 订货会 | 无法介入 |
| 中频 | 清库存 / 促销 / 尾货处理 | 每月 | ★★ | 群甩卖、降价 | 补充 |
| 中频 | 客户归属与团队管理 | 持续 | ★★ | CRM（多数没有） | 补充（轻 CRM：线索归属、跟进记录） |
| 低频 | 分销渠道拓展（找下游门店 / 小批发） | 每季度 | ★★ | 业务员跑市场 | 补充：平台上的门店 / 小批发即是他们的潜在渠道 |
| 低频 | 冬储 / 套保 / 资金策略 | 每年 | ★ | 老板 + 行情 | 可选 |
| 低频 | 融资 / 供应链金融 | 需要时 | ★ | 银行、托盘 | 无法介入 |
| 低频 | 招人 | 偶尔 | ★ | 招聘平台、同行 | 可选（行业人才流动是隐性需求） |

### 8.5 结论
- **依赖类型：工具型 + 增量型，付费意愿最强。** 他们不缺行情、不缺货，缺的是"低成本、可管理的获客"和"品牌"。
- **必须吗？不必须但很想要。** 这是平台**商业化的核心客户**（付费认证、营销工具、线索包）。
- **关键洞察**：中型批发商的诉求是**"营销 + 团队管理"的组合**——他们要的不只是曝光，而是"曝光带来的线索归公司、按业务员归属、能考核"。这与小贸易商 / 小批发只要"我自己接到客户"不同。
- **风险**：他们不会把底价放到公开平台；平台若强推"公开报价"，他们会用"电议""区间价"应付，供给质量下降。必须提供"价格可见范围可控"的机制。
- **切换触发点**：老板看到"业务员用平台名片 / 海报带来了可归因的询价"；或一次成功的品牌活动。

## 9. 卖钢材的大批发商

### 9.1 画像
- 谁：区域头部钢贸 / 钢厂大协议户 / 国企贸易公司，月销数万吨以上，多钢厂多品类，有加工配送中心、物流、仓储甚至金融（托盘、保理）板块，有自己的 IT 团队和 ERP / 在线系统，部分自建了商城或小程序。
- 下游：大终端、大工程、中小批发商（**他们是中小批发和小贸易商的上游**）。
- 决策：高度组织化，采销分离，价格由决策层定，业务员执行；对外信息高度谨慎。
- 商业模式：赚钢厂返利 + 期现套利 + 资金收益 + 分销价差，**是"价格制定者"，不是"价格接受者"**。

### 9.2 当前怎么干
- 行情：自己就是行情来源之一，有研究员，付费全套数据。
- 销售：大客户直营 + 分销体系（发展下游批发商 / 门店）+ 招投标 + 自有线上系统。
- 不公开报价，对不同层级客户不同价，尾货 / 非标另行处理。
- 与平台的关系：历史上被找钢网等平台"教育"过，态度是"可以合作，但不交客户、不交价格"。

### 9.3 核心痛点
1. **分销渠道的广度与掌控**：想触达更多小批发 / 门店做分销，但业务员覆盖有限。
2. **尾货 / 非标 / 冷门规格处理**：占资金，卖不掉。
3. **品牌与钢厂关系的对外展示**：想让市场知道"XX 钢厂华东总代"。
4. **数据**：想知道区域供需、下游库存与需求动向。
5. 基本不缺行情、不缺货、不缺大客户。

### 9.4 需求分层

| 频率 | 需求 | 具体场景 | 必须度 | 当前方式 | 平台相对现状 |
|------|------|---------|-------|---------|-------------|
| 高频 | 行情 / 宏观 / 期现 | 每天 | ○（已完全满足） | 自有研究 + 全套付费数据 | 无价值 |
| 高频 | 大客户维护、钢厂关系 | 每天 | ○ | 线下 | 无法介入 |
| 高频 | 库存 / 资金 / 出库 | 每天 | ○ | 自有系统 | 无法介入 |
| 中频 | 尾货 / 非标 / 冷门规格清理 | 每月 | ★★ | 内部消化、低价甩 | **补充**：面向全网中小买家的处理渠道有价值 |
| 中频 | 分销渠道拓展（找下游小批发 / 门店） | 每月 | ★★ | 业务员跑区域 | **补充**：平台上聚集的中小卖方就是他们的渠道 |
| 中频 | 品牌 / 代理身份曝光 | 持续 | ★ | 官网、展会 | 补充（认证总代、企业主页） |
| 低频 | 区域供需数据 / 下游动向 | 每季度 | ★★ | 自有研究、走访 | **补充**：平台的搜索 / 询价数据是独有的需求侧信号，对他们是稀缺品 |
| 低频 | 招聘 / 挖人 | 偶尔 | ★ | 招聘平台 | 可选 |
| — | 公开挂价卖货 | — | ○ 抵触 | — | **不要指望**：他们不会公开价格，也不会把客户交给平台 |

### 9.5 结论
- **依赖类型：生态合作型，不是用户。** 不会每天用，不会让业务员在平台上找客户。
- **必须吗？完全不必须。** 平台对他们是"多一个渠道、多一份数据"。
- **关键洞察**：对平台而言，大批发商的价值是**"供给锚"和"信誉锚"**——有他们在（即使只挂尾货、只做认证展示），小贸易商就有货可找、买方就觉得平台"有真货"。争取他们的方式不是产品功能，而是**招商 / BD + 数据回报 + 分销渠道故事**。
- **风险**：他们可能是**潜在竞争者**（自建平台）或对平台持防御态度（怕被去中间化、怕价格透明）。不要把他们当成需要"转化"的用户，当成需要"结盟"的合作方。

| 现状方式 | 它解决了什么 | 它解决不了什么 | 平台的位置 |
|------|------|------|------|
| 微信群 / 朋友圈 / 私聊 | 快、熟、可信、顺带维护关系 | 不结构化、找不到、过时、无沉淀、无归因、生人不可信、跨区域盲 | **嵌入 + 补充**：做"结构化资源池 + 可归因传播 + 身份信用"，结果回流微信 |
| 电话 | 最快确认"有没有、多少钱" | 一次只能问一个人 | 补充：一次问多家的"询价广播" |
| 钢材市场物理聚集 | 面对面看货、建信任、顺便找货 | 只覆盖本地、耗时 | 补充：跨市场 / 跨区域的"线上市场" |

| 央企 / 国企集采平台 | 合规采购 | 只服务体系内 | 无法介入，绕开 |
| ERP / 进销存 | 内部管理 | 不对外 | 无法介入，可对接（库存表同步） |
| 抖音 / 快手 / 地图 / 58 | 面向个人买家的流量 | 商家不会做、无行业结构 | 补充：把商家"送"到这些渠道（生成内容 / 页面），而不是自建流量池 |

### 10.4 六个跨群体的关键洞察

1. **中枢是买卖双身份的中小钢贸商。** 小贸易商、小批发、门店三类人每天既找货又找客，是唯一每日打开的用户，也是供给、内容、传播三种东西的来源。其他群体是围绕他们的"两端"。
2. **高频需求都不值钱，值钱的需求都低频。** 看行情高频但没人付费；一单紧急找货、一个新客户低频但价值巨大。产品必须"高频养习惯（行情、库存表发布），低频兑现价值（找货、线索）"，且要让高频行为自然导向低频价值（看行情的人顺手看到资源，发库存表的人顺手拿到线索）。
3. **价格透明是双刃剑，必须做"可见范围可控"。** 买方（终端、工程、个人、门店对上游）要透明；卖方（中大批发、门店对散客）要不透明。可行的做法是"参考价区间 + 卖方对特定人群实报 + 电议"，而不是公开挂价。强推透明会赶走供给。
4. **真正被筛选的不是价格，是交易条件。** 工程要垫资 + 送到工地 + 品牌合规；终端要材质 + 定尺 + 加工 + 质保书；个人要零剪 + 送货 + 不被坑。只展示"品名规格价格"的资源信息对买方价值有限；"接受账期 / 商票""可加工""可零剪""送货范围""一手 / 二手"这些标签才是差异化。
5. **使用者 ≠ 决策者 ≠ 受益者。** 终端的采购员、工程的材料员、批发商的业务员是使用者，他们的个人动机（向老板交差、保护自己的客户、不想被换掉）决定了会不会用。产品设计要给"使用者"个人好处（价格依据、每人一码、线索归属），而不只是给"公司"省钱。
6. **信任在没有交易数据的平台上如何建立**是根本问题。不做线上交易就没有履约记录，只能靠：实名 / 企业认证 + 钢厂代理认证 + 从业年限 + 同行 / 老客户背书 + 线索反馈（"已联系 / 已成交"回填）+ 信息新鲜度记录。信用体系不能等交易，要从"信息可靠度"开始积累。

### 10.5 群体优先级建议（仅从需求侧推导）

| 优先级 | 群体 | 角色定位 | 理由 |
|------|------|------|------|
| P0 | 小贸易商 | 活跃引擎 + 传播节点 + 需求发起者 | 刚需、每日、天然裂变、免费生产内容 |
| P0 | 小批发 / 小门店 | 供给密度主力 | 真实库存、每天更新、有曝光动机 |
| P1 | 中型批发商 | 商业化核心（付费方） | 缺获客与品牌、有付费能力、需要团队管理 |
| P1 | 工程项目购料方 | 高价值需求侧 | 单量大、有"换城市找供应商 / 紧急补料"的明确时刻、是卖方最想要的线索 |
| P2 | 钢材门店 | 供给 + 需求双向节点 | 与小批发高度重叠，随小批发一起做 |
| P2 | 终端用料企业 | 高价值低频需求侧 | 紧急找货 + 价格依据两个场景，其余难介入 |
| P3 | 经常采购的个人 | 门店的线索来源 | 自身低留存，作为"给门店的礼物"运营，流量在站外 |
| 合作方 | 大批发商 | 供给锚 + 信誉锚 + 数据买家 | 不当用户当伙伴；BD 而非产品驱动 |

### 10.6 需要用调研验证的关键假设

以上分析是基于行业经验的结构化判断，落地前建议用 30~50 个深访 + 100 份以上问卷验证以下假设（按重要性排序）：

1. 小贸易商每天在"找货"上花多少时间？其中多大比例是微信里找不到、需要跨圈层的？（决定"找货"能否成为替代路径）
2. 小批发 / 中批发商每天发库存表的实际触达与反馈率是多少？他们是否愿意为"知道谁看了"改变发布方式？
3. 中型批发商愿意为"可归因的新客户线索"付多少钱？按线索付费还是按年付费？
4. 工程材料员在"新城市开项目"时找供应商平均花几天、问几个人？"接受账期"信息对他们的筛选权重有多大？
5. 终端采购员一年发生几次紧急缺料？平均加价多少？是否愿意为此提前在平台留下"我要什么"？
6. 各类卖方对"价格对谁可见"的真实底线：对同行 / 对散客 / 对 B 端买家 / 对平台运营，分别接受什么程度的可见？
7. 个人买家从哪里找钢材门店（抖音 / 地图 / 熟人 / 市场）？比例决定"把门店送出去"应该优先对接哪个渠道。
8. 采购员 / 材料员 / 业务员在使用第三方平台时的个人顾虑（被公司稽核、被同行看见、被上游截客）是否会阻止使用？

## 附：访谈提纲（每类 6 问，可直接使用）

**通用 6 问**
1. 昨天一天，你和"钢材"有关的事从早到晚做了哪些？分别用什么工具 / 找了谁？
2. 上一次你觉得"找货 / 找客户 / 看价"特别费劲是什么时候？最后怎么解决的？花了多少时间 / 多付了多少钱？
3. 你现在在多少个微信群？每天真正会看的有几个？为什么是这几个？
4. 你愿意让谁看到你的价格？不愿意让谁看到？为什么？
5. 如果有一个地方能一次看到本地所有有货的商家 / 所有在找货的买家，你第一反应是什么？会担心什么？
6. 你为哪些和生意有关的信息或工具付过费？多少钱？值不值？

**分群追加问**
- 终端：一年几次紧急缺料？向老板汇报价格时用什么依据？换供应商最大的阻力是什么？
- 工程：新项目怎么选供应商？"能垫资"和"价格低"哪个优先？月度调差用哪个价？
- 门店：上游有几家？怎么知道自己拿的价合不合理？散客从哪来？
- 个人：怎么判断不被坑？愿不愿意多付一点买"放心"？换个地方施工怎么找店？
- 小贸易商：每天翻多少群找货？生客怎么建立信任？最怕平台做什么？
- 小批发：库存表发给谁？谁会回？业务员走了带走多少客户？
- 中批发：新客户主要从哪来、成本多少？公司对业务员客户归属怎么管？愿不愿意公开"代理身份"但不公开价格？
- 大批发：尾货怎么处理？下游分销商怎么发展？对第三方平台的历史经验是什么？
