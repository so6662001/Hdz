# 07 · 实施路线与验收标准

> 所属：AI 货袋子获客系统 v0.1  
> 说明：阶段按**能力边界**划分，不做日历排期；每阶段给出范围、依赖、交付物与验收口径。

## 1. 分阶段范围

### 阶段 0 · 方案确认与原型

- 确认 README 决策点 Q1–Q8 与各分册修改意见。
- 高保真 HTML 原型（按 06 分册第 13 节优先级），先出看板 / 会话工作台 / 任务配置 / 线索四页。
- 交付：确认后的设计文档 v1.0 + 原型。

### 阶段 1 · 核心闭环 MVP（低风险渠道）

| 范围 | 内容 |
|------|------|
| 后端 | `hdz-ai-acquisition` 模块骨架、20 张表、多租户；线索中心（去重/分配/状态机/时间线）；话术引擎（规则匹配 + 变量渲染 + 个性化校验 + 禁词）；触达引擎（队列 + RiskGuard 节流）；会话与跟进引擎（入站路由、拒绝词、升级、跟进调度）；自动化任务（NL 解析 → JobSpec → XXL-Job，dry-run）；看板聚合 + 实时计数；审核单；黑名单；开通向导接口 |
| 渠道 | `HdzInternalAdapter`（圈子/询价/海报扫码/站内消息）、`WeComAdapter`（客户联系发消息、客户群群发、群机器人、微信客服回调、联系我二维码）、`ForumHttpAdapter`（1–2 个目标论坛的抓取与回帖） |
| AI | `IntentClassifier`、`ReplyClassifier`、`NlTaskParser`、`Moderation`（经 ModelGateway）；`MessagePersonalizer` 默认需人工确认 |
| 前端 | 向导、看板、线索列表/详情、会话工作台、触达记录、话术库、任务、跟进、审核、渠道账号（企微/站内/论坛）、设置 |
| 集成 | 企微通知（高意向/待人工/待审核/账号异常）、线索中心单向同步、海报系统 `/shares` 出码（分发到企微群/朋友圈/论坛） |
| 不含 | 执行端 App 与所有 RPA 渠道；抖音/小红书 |

依赖：ModelGateway 可用；企微自建应用权限；至少一个目标论坛账号。

### 阶段 2 · 执行端与 RPA 渠道（灰度）

| 范围 | 内容 |
|------|------|
| 执行端 | Android 获客助手 App（绑定、心跳、指令执行、回执、截图、风控信号、离线队列）；技能：微信 读群/读朋友圈/私聊/群回复/发朋友圈；WebSocket 执行端网关独立部署 |
| 后端 | `RpaAdapter`、`ExecutorGateway`、设备管理、养号曲线、熔断、运营总闸、风控事件页 |
| 渠道 | 个人微信（小号档位）；抖音开放平台（自家视频评论读取/回复、企业号私信回调）；小红书（网页版发笔记 + 自家笔记评论） |
| 灰度 | 3–5 家试点商家、每家 1–2 台小号设备；风控参数取默认下限；每日审视 BLOCKED 率与 UI_CHANGED |

### 阶段 3 · 扩展抓取与运营化

- 抖音 / 小红书 他人评论区关键词抓取（RPA，独立开关，默认关闭）。
- 云手机部署形态；技能包远程更新；多执行端网关节点。
- 话术周报、A/B 变体统计、AI 草拟话术、AI 建议回复（RAG）。
- 行业话术包扩充；运营用量看板；订阅计费对接。

## 3. 验收用例（对应需求"手动添加 5 条测试线索，看全流程能不能跑通"）

### 3.1 前置

- 商家完成向导步骤 1–3；企微已授权；至少 1 个站内渠道启用；话术库已导入行业包；4 个预设任务已确认。
- 设置测试白名单为验收人员的企微/微信账号。

### 3.2 用例

| # | 用例 | 步骤 | 预期 |
|---|------|------|------|
| T1 | 手工建 5 条测试线索 | 向导步骤 4 添加 5 条（其中 1 条故意不填昵称） | 5 条 `is_test=1` 线索，阶段 NEW，时间线有 CAPTURED(手工) |
| T2 | 触达试运行（暴露变量缺失） | 对"10 点发送触达"任务点 [试运行] | 4 条预览正常并列出命中变量；1 条报 `ACQ-2001 缺少 nickname`，任务运行状态 PARTIAL，不发送任何消息 |
| T3 | 修改指令后重跑 | 补齐昵称或修改话术加入降级（"您好"）→ 重新试运行 → 正式运行 | 5 条 SENT；`lead.stage=CONTACTED`；触达表有变量快照；企微/站内实际收到消息，且每条含昵称与来源 |
| T4 | 回复命中关键词 | 用测试号回复"多少钱一吨" | 入站消息入库；命中 RULE 价格话术；因 `requires_human` 发送过渡语并生成审核单；企微通知负责人；会话 NEED_HUMAN |
| T5 | 审核报价 | 负责人在审核页填写报价并批准 | 报价消息以 USER 身份发送；审核单 APPROVED_SENT；时间线 APPROVAL_DONE |
| T6 | 回复"再考虑" | 测试号回复"我再考虑一下" | 命中异议话术；自动回复；生成 72 小时后跟进任务；看板"谁该跟进"在到期后出现 |
| T7 | 跟进任务执行 | 将跟进 due_at 改为当前时间，手动运行"14:00 跟进未回复" | 二次话术发送；`auto_follow_count=1`；再次运行达上限后线索 SILENT |
| T8 | 拒绝词 | 测试号回复"别发了" | 拉黑；stage LOST(REFUSED)；后续对该线索的触达返回 `ACQ-2003` |
| T9 | 高意向 | 测试号回复"要 200 吨 HRB400 发到苏州" | LLM 抽取实体（数量/规格/地址）→ stage HOT → 企微通知；看板"谁快成交"出现 |
| T10 | 看板刷新 | 手动运行"17:00 更新看板" | `stat_daily` 当日行生成，数值与实际一致（触达 5、回复 3、高意向 1、流失 1、审核 1） |
| T11 | 自然语言任务解析 | 输入"每周一早上八点半给三天没回复的人再发一次案例" | 解析为 FOLLOW_UP，cron `0 30 8 ? * MON`，filter 无回复 ≥3 天，话术=案例类；歧义提示可修改 |
| T12 | 抓取（站内/论坛） | 在圈子发一条"求推荐螺纹钢供应商"，运行抓取任务 | capture_raw 入库；意图 ASK_RECOMMEND 分 ≥60；自动建线索并分配；来源摘要正确 |
| T13 | 海报分发 | 选一张海报分发到 1 个企微群 + 论坛版块 | 每目标获得不同渠道码与成图；发送成功；扫码后 `poster_dispatch_item.scan_count+1`，新增 POSTER_SCAN 来源线索 |
| T14 | 风控节流 | 把某账号小时上限设为 2，触达 5 条 | 前 2 条即时，其余排队并显示预计时间；不超限 |
| T15 | 熔断 | 模拟连续 2 次 BLOCKED 回执 | 账号 RESTRICTED、队列暂停、告警；人工解除后恢复 |
| T16 | 租户隔离 | 用另一商家账号查询 | 看不到上述任何数据 |
| T17 | 追加不可改 | 尝试通过接口修改/删除 lead_event | 无对应接口/返回 405 |

### 3.3 非功能验收

| 项 | 指标 |
|----|------|
| 列表接口 P95 | ≤ 500 ms（10 万线索规模） |
| 入站消息到自动回复入队 | ≤ 3 s（不含风控延迟） |
| 任务 dry-run 200 条预览 | ≤ 10 s |
| 执行端指令回执超时率 | ≤ 5%（阶段 2） |
| LLM 意图识别缓存命中率 | ≥ 60%（重复内容） |
| 数据清理任务 | 到期数据 24 h 内清除 |

## 4. 风险与对策

| 风险 | 影响 | 对策 |
|------|------|------|
| 微信/抖音/小红书 RPA 账号被限制或封禁 | 商家账号损失、投诉 | 小号档位、养号曲线、默认下限配额、熔断、风险告知书、官方渠道优先并逐步替代 |
| App 版本升级导致技能脚本失效 | RPA 渠道停摆 | `UI_CHANGED` 自动暂停 + 告警；技能包热更新；维持 1–2 个版本回归测试机 |
| LLM 误判意图或误匹配话术 | 触达不相关用户、回复不当 | 阈值 + 置信度门槛；规则优先；AI 润色需确认；所有 AI 输出可回溯；每周抽样复核 |
| 个人信息合规争议 | 法律风险 | 只处理公开意图信息、敏感串剔除、保留期、退订、法务复核（05 分册清单） |
| 触达量目标与风控冲突 | 商家预期落空 | 向导阶段明确告知各渠道配额；用多渠道叠加而非单渠道拉高；看板展示"配额利用率" |
| 执行端网络/电量/后台限制 | 指令超时 | 前台服务 + 白名单引导；低电量降配；离线队列；超时改派回复类任务 |
| 与线索中心/海报系统接口变动 | 集成失效 | 通过 `acquisition-api` 与内部事件解耦，契约测试 |
