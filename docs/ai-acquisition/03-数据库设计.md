# 03 · 数据库设计

> 所属：AI 货袋子获客系统 v0.1  
> 约定：MySQL 8.0，InnoDB，utf8mb4；表前缀 `hdz_acq_`；所有业务表含 `merchant_id`（租户）与审计字段；主键 `BIGINT` 雪花 ID；软删除仅用于配置类表，业务流水表**只追加**。  
> 与已有系统复用的表（不在本模块建）：`poster_session` / `poster_share` / `poster_scan` / `poster_lead`（海报系统）、`knowledge_item`（企业资料库）、`hdz_wechat_notify_config`（企微通知）、`hdz_follow_up_record`（线索中心跟进）。

---

## 4. 状态机

### 4.1 线索 `stage`

见 01 分册第 4 节。允许的自动迁移：`NEW→CONTACTED`（触达 SENT）、`CONTACTED→REPLIED`（入站）、`REPLIED→HOT`（分值/实体）、`CONTACTED/REPLIED→SILENT`（自动跟进次数达上限）、`*→LOST`（拒绝词）、`SILENT→NEW`（静默期后再抓到意图）。`WON`、`LOST(非拒绝词)` 仅人工。

### 4.2 触达 `status`

```
DRAFT → PENDING_APPROVAL → QUEUED → SENDING → SENT
  │          │(拒绝)          │(取消)     ├─▶ FAILED (retry ≤3 → QUEUED)
  └─────────▶ CANCELLED ◀──────┘          └─▶ BLOCKED (账号熔断)
```

### 4.3 会话 `status`

`AUTO ⇄ NEED_HUMAN → HUMAN → CLOSED`；`HUMAN` 状态下系统不再自动回复，销售可"交还机器"回到 `AUTO`。

### 4.4 渠道账号 `status`

`OFFLINE → ONLINE ⇄ RESTRICTED(熔断中) → NEED_VERIFY → BANNED`；`DISABLED` 人工停用。

## 6. 数据访问约束

1. **多租户**：MyBatis-Plus `TenantLineInnerInterceptor` 自动注入 `merchant_id`；`hdz_acq_script.merchant_id=0`（行业模板）与 `hdz_acq_risk_policy.merchant_id=0` 通过显式忽略租户拦截查询。
2. **只追加表**：`hdz_acq_lead_event`、`hdz_acq_message(IN)`、`hdz_acq_capture_raw` 不提供 update/delete Mapper 方法（仅归档清理任务可按保留期物理删除）。
3. **敏感字段**：`phone_enc / wechat_id_enc / credential_enc` 通过 MyBatis TypeHandler 加解密；列表接口一律脱敏。
4. **大字段**：`content`、`spec_json` 等不参与列表查询，详情单独接口。
5. **归档**：按 3.13 保留期由清理任务分批删除；`stat_daily` 与 `script_stat_daily` 永久保留供趋势分析。
