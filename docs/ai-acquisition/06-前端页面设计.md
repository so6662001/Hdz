# 06 · 前端页面设计（低保真）

> 所属：AI 货袋子获客系统 v0.1  
> 技术：Vue 3 + Element Plus + Pinia + ECharts，作为商家后台 / 运营后台的独立路由模块 `/acquisition/*` 嵌入（与分站、广告、海报模块同一方式）。  
> **本阶段只给页面清单、导航结构与文字线框，不出高保真 HTML**；待方案确认后再做高保真原型（优先：看板、线索、会话工作台、任务配置）。

```

│ ├─ 拒绝 ──────────▶ ◼ 结束 · 置为 流失(拒绝)                                           │

│ │                    └─ 完成 ─▶ ↺ 回到「等待回复」                                     │
```

节点右侧 `[⋯]`：编辑 / 在后面插入 / 删除（删除中间节点自动把上游接到下游）。`等待回复` 的分支键从话术分类 + 固定键（未回复 / 拒绝 / 提到实体 / 其他）中勾选，未勾选的类别归入"其他"。

## 12. 交互与技术要点

| 项 | 方案 |
|----|------|
| 状态管理 | Pinia：`useAcqSessionStore`（角色/权限/商家配置）、`useWorkbenchStore`（会话列表、未读、SSE/WS 推送） |
| 实时性 | 会话工作台通过 SSE（或复用平台 WebSocket）接收新消息/状态变更；任务运行进度 SSE |
| 表格 | 统一 `AcqTable` 封装（筛选持久化到 URL query、列配置、导出） |
| 变量编辑器 | 话术内容用带变量高亮的 contenteditable/Monaco 轻量封装，点击变量面板插入，实时校验 |
| 流程编辑器 | 一期纵向树：自研递归 `FlowNode` 组件渲染 DAG（`GoTo` 以"↺ 回到 X"引用显示，不画回边），本地 JSON 状态 + 撤销栈；二期可切换 AntV X6/LogicFlow 自由画布，同一 definition JSON |
| 权限 | `v-permission="'acquisition:lead:edit'"` 指令；销售视角自动追加 `ownerUserId=me` |
| 脱敏 | 手机号默认 `138****1234`，点击显示需 `acquisition:lead:contact:view` 且记审计 |
| 空态 | 未完成向导的页面显示引导卡片跳转向导 |
| 移动端 | 一期不做独立移动端；销售的移动侧提醒走企微通知，点击链接打开 PC 页 |
