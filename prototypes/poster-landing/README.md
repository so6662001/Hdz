# 货袋子 · 行情海报落地页高保真原型

> 场景：平台提供行情数据 + 商家自有现货资源 → 生成带二维码的海报/落地页 → 销售员转发 → 客户扫码进入企业落地页 → 询价留资 → 线索归因到销售员与企业。
> 本目录在已有 5 种海报样式之外，新增 **10 种风格的落地页**、**企业自定义设计器**、**视频海报生成器**，全部为可交互的 HTML 原型。

## 打开方式

直接用浏览器打开 `index.html`（无需构建、无外部依赖），或在本目录启动任意静态服务器：

```bash
cd prototypes/poster-landing && python3 -m http.server 8080
# 访问 http://localhost:8080/
```

建议用 Chrome 设备模拟（375×812）查看落地页，设计器与视频生成器为桌面端界面。

## 每套落地页的统一闭环

1. 首屏 3 秒内看到"今日主推价 + 涨跌"（主推品种大字）。
2. 主流品种行情列表 + 近 8 日走势 + 今日点评（数据来自平台行情服务）。
3. 本店现货资源，每条可直接"询价"（带品名规格预填）。
4. 销售员名片 + 二维码固定在末屏，可长按识别。
5. 底部固定 CTA：电话 / 微信 / 询价（留资底部弹层 → 提交成功页显示归因到企业与追踪码）。
6. 右下角"生成海报"按钮：一键弹出与落地页同风格的 9:16 海报图预览，支持保存/分享。

## 企业自定义设计器（designer.html）

- **风格底稿**：10 套风格一键套用配色/字体/背景，可再自由调整。
- **品牌**：企业简称、标题、口号、Logo、主色/强调色、浅/深/纸质/品牌色背景、4 种字体、圆角、信息密度。
- **内容板块**：主推大字、行情列表、走势图、点评、现货资源、名片二维码、紧迫感（倒计时/库存进度），可开关与排序。
- **数据**：行情品种多选与主推品种（来自平台行情）、现货资源多选（来自我的资源库）、价格显示方式（明码/区间/电议）。
- **转化**：主按钮文案、次按钮组合、留资表单字段、紧迫感元素。
- **二维码与追踪**：小程序码/企微活码/H5 码、绑定销售员、每人一码批量生成。
- **预览**：落地页 / 9:16 海报 / 1:1 方图 / 15s 视频 四种产物实时切换。
- **产出**：保存为企业模板、生成落地页 + 海报图、配置 JSON（可用于 API 批量生成）、近 7 日效果数据。

## 视频海报生成器（video.html）

- 5 段分镜：品牌开场 → 今日行情（数字滚动）→ 走势 + 点评 → 现货资源 → 名片 + 二维码（停留 3 秒）。
- 时间轴播放/暂停/跳转、总时长 10~30s、9:16 / 1:1 画幅、转场、AI 配音、字幕、BGM、品牌水印、片尾类型。
- 导出 MP4 流程模拟（服务端渲染 → 配音 → 字幕 → 合流 → CDN），一键发朋友圈/视频号，团队批量（每人专属片尾）。
- "每日 07:30 自动生成"：用最新行情自动渲染并推送到销售员微信，销售员只需转发。

## 研发落地要点

- **数据注入**：落地页与海报由同一份配置 JSON 驱动（见设计器右侧），服务端按模板渲染 HTML（落地页）与图片（海报，无头浏览器截图或 Canvas 渲染）。
- **追踪**：每次生成携带 `spread_code`（销售员 × 模板 × 时间），落地页所有行为（浏览/询价/拨号/加微信）上报并归因。
- **视频**：服务端合成（FFmpeg + 模板渲染逐帧或 Lottie/Remotion 类方案），异步任务 + 完成后推送。
- **模板系统**：风格 = 主题变量（配色/字体/圆角/密度）+ 板块布局 + 特色装饰；企业模板 = 风格 + 品牌 + 板块配置，存为 JSON。
- **性能**：海报图与视频走 CDN；落地页首屏静态化，行情数据每日更新后重渲染缓存。
