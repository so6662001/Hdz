# 货袋子 · 行情海报落地页高保真原型

> 场景：平台提供行情数据 + 商家自有现货资源 → 生成带二维码的海报/落地页 → 销售员转发 → 客户扫码进入企业落地页 → 询价留资 → 线索归因到销售员与企业。
> 本目录在已有 5 种海报样式之外，新增 **10 种风格的落地页**、**手机端 H5 海报生成器**、**企业自定义设计器**、**视频海报生成器**，全部为可交互的 HTML 原型。

## 打开方式

直接用浏览器打开 `index.html`（无需构建、无外部依赖），或在本目录启动任意静态服务器：

```bash
cd prototypes/poster-landing && python3 -m http.server 8080
# 访问 http://localhost:8080/
```

建议用 Chrome 设备模拟（375×812）查看落地页，设计器与视频生成器为桌面端界面。

## 每套落地页的统一闭环

1. 首屏 3 秒内看到"今日主推价 + 涨跌"（主推品种大字）。
2. 主流品种行情列表 + 近 8 日走势 + 今日点评（数据来自平台行情服务）。
3. 本店现货资源，每条可直接"询价"（带品名规格预填）。
4. 销售员名片 + 二维码固定在末屏，可长按识别。
5. 底部固定 CTA：电话 / 微信 / 询价（留资底部弹层 → 提交成功页显示归因到企业与追踪码）。
6. 右下角"生成海报"按钮：先弹出同风格 9:16 快速预览，点「生成高清海报图」进入手机端生成器（`mobile-poster.html?style=…`）真正渲染出图片。

## 手机端 H5 海报生成器（mobile-poster.html）

- **纯前端出图**：用 Canvas 2D 在手机上直接渲染 1080×1920 海报（`canvas.toDataURL`），不依赖服务端截图；真实环境在微信内可 `wx.previewImage` 长按保存，App 内可直接写相册。
- **10 种风格**：与 10 套落地页一一对应（品牌行 / 标题装饰 / 主推大字 / 行情列表 / 走势 / 点评 / 现货 / 名片二维码），左右滑动或点缩略图切换。
- **内容可调**：主推品种、行情条数（4/6）、走势图与点评开关、现货条数（2/3/4）、现货价格明码/电议、销售员、是否显示电话、二维码类型、自定义标题。
- **自适应排版**：内容超出版面时自动切换紧凑尺寸，仍溢出则按"行情条数 → 走势 → 现货条数 → 点评"顺序精简，并在预览下方提示。
- **入口**：任一落地页右下角「生成海报」→「生成高清海报图」；总览页工具卡；`?style=<id>&back=1` 供落地页跳入后返回。

## 企业自定义设计器（designer.html）

- **风格底稿**：10 套风格一键套用配色/字体/背景，可再自由调整。
- **品牌**：企业简称、标题、口号、Logo、主色/强调色、浅/深/纸质/品牌色背景、4 种字体、圆角、信息密度。
- **内容板块**：主推大字、行情列表、走势图、点评、现货资源、名片二维码、紧迫感（倒计时/库存进度），可开关与排序。
- **数据**：行情品种多选与主推品种（来自平台行情）、现货资源多选（来自我的资源库）、价格显示方式（明码/区间/电议）。
- **转化**：主按钮文案、次按钮组合、留资表单字段、紧迫感元素。
- **二维码与追踪**：小程序码/企微活码/H5 码、绑定销售员、每人一码批量生成。
- **预览**：落地页 / 9:16 海报 / 1:1 方图 / 15s 视频 四种产物实时切换。
- **产出**：保存为企业模板、生成落地页 + 海报图、配置 JSON（可用于 API 批量生成）、近 7 日效果数据。

## 视频海报生成器（video.html）

- **Canvas 时间轴确定性渲染**：1080×1920 画面由 `draw(t)` 按时间逐帧绘制，任一时刻可复现；预览即导出效果，服务端用同一段渲染代码逐帧输出 + FFmpeg 合成 MP4。
- **6 段分镜（可开关、时长按比例自动分配）**：品牌开场（Logo 光晕 + 企业名逐字揭示）→ 主推行情（大数字滚动、涨跌胶囊弹出、8 日统计块、品种跑马灯）→ 行情矩阵（五大品种错落入场 + 涨跌力度条）→ 走势点评（走势线自绘、终点脉冲、点评打字机）→ 本店现货（卡片飞入 + 老价印章）→ 名片二维码（圆形转场、二维码逐块生成、脉冲提示）。
- **电影感效果层**：渐变 + 游动光斑 + 粒子背景、每镜开场光带扫过、胶片颗粒与暗角、顶部分段进度条、品牌水印、底部字幕；均可单独开关。
- **4 套调色**：深蓝金融 / 钢厂工业 / 喜报红金 / 极简商务。
- **控制**：播放/暂停（点击画面或空格）、进度条拖动逐帧查看、分镜标记跳转、15/20/30s 总时长、主推品种、现货条数。
- **导出**：服务端 MP4（含 AI 配音、字幕）流程模拟；**浏览器端直接录制 WebM**（`canvas.captureStream` + `MediaRecorder`，真实可下载）；一键发朋友圈/视频号；团队批量（每人专属片尾）；每日 07:30 自动生成。
- **配音脚本**随分镜自动生成并展示时间点，便于接 TTS。
- 调试参数：`?pal=fin|ind|red|white&t=秒` 定格到某一时刻。

## 转发到微信群的呈现（wechat-share-preview.html）

- **H5 链接卡片**：标题（2 行）+ 描述（1~3 行）+ 48px 正方形缩略图 + 来源。最通用，点开即落地页；**必须接入微信 JS-SDK 配置 `title / desc / link / imgUrl`**，否则退化为"域名 + 一串 URL"的默认卡片。
- **小程序卡片**：标题 + 5:4 大图 + "小程序"标识，群里曝光最好，且自带用户身份可免填手机号留资。
- **海报图片**：纯图片消息，长按识别二维码进落地页；群里为缩略显示，需点开放大再长按。
- 建议组合：群里 "一句话 + H5 链接卡片 + 海报图"；朋友圈 "海报图 + 链接"。
- 标题/描述由服务端按当日行情 + 销售员 + 模板动态生成；`link` 保留 `spread_code` 做归因；缩略图优先"行情大字"或"海报缩略"。

## 研发落地要点

- **数据注入**：落地页与海报由同一份配置 JSON 驱动（见设计器右侧），服务端按模板渲染 HTML（落地页）与图片（海报，无头浏览器截图或 Canvas 渲染）。
- **追踪**：每次生成携带 `spread_code`（销售员 × 模板 × 时间），落地页所有行为（浏览/询价/拨号/加微信）上报并归因。
- **视频**：与 video.html 相同的 Canvas `draw(t)` 在服务端（Node + node-canvas / 无头 Chrome）逐帧输出 → FFmpeg 合成 H.264 + TTS 配音 + 字幕；异步任务 + 完成后推送。浏览器端可 MediaRecorder 即时录制 WebM 供预览分享。
- **模板系统**：风格 = 主题变量（配色/字体/圆角/密度）+ 板块布局 + 特色装饰；企业模板 = 风格 + 品牌 + 板块配置，存为 JSON。
- **性能**：海报图与视频走 CDN；落地页首屏静态化，行情数据每日更新后重渲染缓存。
