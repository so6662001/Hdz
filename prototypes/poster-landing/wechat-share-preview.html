三种形态怎么选

H5 链接卡片最通用。标题 + 描述 + 48px 小图 + 来源。优点：可放完整行情文案，点开即落地页，支持 URL 带追踪码。注意：必须配 JS-SDK 分享参数，否则退化为下方"默认丑链接"。 小程序卡片标题 + 大图（5:4）+ "小程序"标识。优点：大图最抢眼，群里曝光最好，且天然带用户身份，扫码后留资可免填手机号。注意：需要小程序，图要专门出一张 5:4 封面。 海报图片纯图片消息，长按识别二维码进落地页。优点：朋友圈/群里视觉最完整，不依赖任何分享配置。注意：群里是缩略显示，需点开放大再长按，比链接多一步。
建议组合：销售员在群里先发 一句话 + H5 链接卡片（点开即看），紧跟 一张海报图（视觉冲击 + 可保存转发）；朋友圈发 海报图 + 链接。小程序卡片在有小程序后作为群里的主力形态。

研发落地要点

分享配置落地页接入微信 JS-SDK，调用 updateAppMessageShareData（好友/群）与 updateTimelineShareData（朋友圈），传 title / desc / link / imgUrl。不配即出现右下方那种"只有域名 + 一串 URL"的默认卡片，转化率会断崖式下降。 动态文案title/desc 由服务端按当日行情 + 销售员 + 模板实时生成（如"螺纹 3680 ▲20 | 鑫钢现货老价"），每天不同，避免群里看到重复卡片。 追踪码link 中保留 spread_code；被转发者再转发时 SDK 会带上原链接，所有归因仍指向首个销售员（可选择二次分享生成新码归因给转发者）。 缩略图服务端渲染 300×300 正方形：优先"行情大字"（价格 + 涨跌）或"海报缩略"，识别度高于 Logo。 域名与备案H5 域名需在公众号"JS 接口安全域名"配置；避免被微信拦截需 ICP 备案并注意频繁投诉。 打开即留资微信内打开可静默获取 openid（需公众号授权），已授权老客可一键询价免填手机；这是链接卡片相对海报图的最大转化优势。
