# AI 企业经营海报 · 高保真原型

> 企业素材库（图片库 + 可编辑资料库）→ 选图 / 勾选资料（可交给 AI）→ 输入一句需求 → AI 检索资料并按"强视觉冲击"原则生成海报 → 自然语言反复微调；支持 PC 与 H5。
> 设计方案：[`docs/ai-poster/01-方案-AI企业经营海报生成.md`](../../docs/ai-poster/01-方案-AI企业经营海报生成.md)。
> 纯前端、无构建、无外部依赖。原型中的"大模型"由规则模拟（`shared/engine.js` 的 `mockPlan / mockRefine`），正式实现时替换为 ModelGateway 调用，渲染引擎可直接复用。

## 打开方式

```bash
cd prototypes/ai-poster && python3 -m http.server 8080
# http://localhost:8080/index.html
```

## 原型支持的微调指令（规则模拟）

- 冲击力：`更有冲击力 / 更醒目 / 更炸`（已是强冲击则进一步放大标题、精简信息）、`柔和一点 / 低调一点`、`去掉光线装饰 / 去掉光效层`
- 资料：`用企业介绍`、`加上产品介绍 / 服务介绍 / 资质 / 案例 / 团队 / 承诺`（按标题中的品种匹配产品条目）、`不要资料引用`
- 文本：`标题改为「…」`、`副标题改为…`、`电话改成 139…`、`地址改成…`、`联系人改成…`、`价格改成 3690`、`薪资 8K~15K`、`把 A 改成 B`、`换一种说法`
- 排版：`字大一点 / 小一点`、`更简洁 / 更丰富`、`换个版式`、`版式改成 上图下文 / 大字 / 要点 / 卡片 / 全图 / 多图 / 表格`、`全图铺满`、`多图拼贴`、`去掉角标`
- 风格：`红色 / 喜庆 / 商务 / 工业 / 简洁 / 科技 / 黑金 / 国风 / 绿色`、`换个背景`、`背景亮一点`、`加点金色粒子`、`再好看一点`
- 元素：`加 / 去掉 二维码`、`去掉地址`、`去掉电话`、`去掉 Logo`、`去掉副标题`、`去掉图片`、`用第二张图`、`换成刚上传的图`；左栏图片库勾选 / 取消即时换图（≥2 张自动多图拼贴）
- 画幅：`改成竖屏 9:16`、`改成 1:1 方图`、`改成 3:4 朋友圈`
- 版本：工作台「撤销」、版本条点击；H5 左右滑动
- 历史：每次生成 / 微调自动保存；PC 顶栏「历史记录」抽屉（分类 / 时间 / 状态 / 排序 / 收藏 / 搜索，打开继续改 / 再做类似 / 导出 / 删除），欢迎区「最近做过的海报」；H5 首页「最近做的海报」条 + 历史页（分类页签、按日分组、⋯ 操作面板）

## 企业素材库与视觉冲击力

- **图片库**：按 品牌 / 门头、产品、仓库 / 现场、加工 / 物流、人物 / 团队、资质、我上传的 分类；每次海报可勾选 ≤3 张（第 1 张主视觉，≥2 张走多图拼贴），不勾选由 AI 按场景标签与资料关联图片选图。
- **资料库**：企业介绍、品牌介绍、产品介绍（每品种一条）、服务介绍（每服务一条）、优势卖点、资质荣誉、客户案例、团队介绍、服务承诺。每条 = 标题 + 海报要点（短句）+ 完整介绍 + 标签 + 关联图片 + 数字事实。PC「管理资料库」抽屉 / H5 编辑面板可新增、编辑、删除，「AI 提炼要点」从一段介绍生成要点。
- **检索引用**：不勾选 → 按场景 → 资料类映射 + 品种 / 服务标签打分，取最相关 1~2 条（主营目录 3 条），同类只留一条、宁缺毋滥；勾选 → 精确引用。引用结果显示在生成过程「检索企业资料」步骤、AI 回复 chips（📚）与画布信息栏（📚 引用 N 条资料），设计 JSON 的 `kb.cited` 记录来源。
- **冲击力**（`impact`，默认 3 强）：强 = 标题 ×1.12、焦点数字 ×1.18 带发光、放射光线 + 斜切色带 + 大字底纹装饰层、CTA 外发光、图像提示词追加"高对比 / 戏剧性光线 / 电影级"；标准 = 常规；柔和 = 标题 ×0.94、无装饰层。PC 画布工具栏 / H5 需求页可切换，微调可说"更有冲击力""柔和一点"。

## 7 大类 44 场景

| 大类 | 场景 | 默认版式 |
|------|------|---------|
| 产品与货源 | 新品上市 · 到货通知 · 产品特色 · 主营目录 · 库存资源表 · 加工服务 · 物流配送 | split / hero / list / table |
| 现场与实力 | 仓库发货现场 · 加工现场 · 客户接待 · 工程案例 · 企业实力 · 资质荣誉 · 签约合作 · 团队风采 | photo / gallery / split |
| 促销活动 | 特价促销 · 节假日促销 · 周年庆促销 · 限时秒杀 · 清仓甩货 · 拼单团购 · 开业乔迁 | hero / list |
| 品牌与关系 | 客户见证 · 中标喜报 · 活动邀请 · 展会现场 · 直播预告 | card / photo |
| 客户关怀 | 节日祝福 · 节气日签 · 客户感谢 · **生日祝福 · 合作纪念 · 老客户专享 · 关怀慰问 · 客户喜事恭贺 · 心意礼品 · 老友问候** | card / list / split |
| 人才与招商 | 招聘 · 招商合作 | list / hero |
| 通知与提醒 | 通知公告 · 调价通知 · 天气提醒 · 开工大吉 · 知识科普 | card / list |

每个场景内置关键词识别、示例提示词、文案模板与可选角标（如"现场直击""NEW""限时"）；不选场景时由提示词自动识别（节日词 + 促销词 → 节假日促销，周年 / 店庆 → 周年庆，生日 / 生辰 → 生日祝福，合作满 N 年 / 累计供货 / 第 N 车 → 合作纪念，祝贺 + 投产 / 中标 / 开业 → 客户喜事恭贺）。客户关怀类不卖货只走心：默认「标准」冲击力、新增「暖心橙」风格，识别客户称呼（张总 / 李经理）、合作年限、累计吨位、第 N 车、礼品种类等实体。PC / H5 选中带样板的场景后，输入框上方出现该场景的样板 chips（场景按钮上有数量角标），点一下即填入提示词并带上风格 / 版式建议生成，再用自然语言改人名 / 年数 / 语气。正式版由大模型生成文案，样板由运营维护 + 商家"存为我的样板"沉淀。

版式：`hero` 主视觉大字 · `split` 上图下文 · `list` 标题 + 要点卡 · `card` 居中卡片 · `photo` 全图实拍 · `gallery` 多图拼贴（1 大 + 2 小） · `table` 表格清单（品名 / 规格 / 钢厂 / 价格）。

## 与正式实现的对应关系

| 原型 | 正式实现 |
|------|---------|
| `AP.KB.retrieve()`（场景映射 + 标签打分） | 向量检索（资料 embedding）+ 规则加权；`POST /knowledge/retrieve` |
| `AP.KB.apply()`（资料要点融入文案的规则） | 资料作为【企业资料库】上下文进入规划 prompt，由大模型消化并在 `kb.cited` 标注 |
| `AP.KB.distill()` | `ModelGateway.distill()` → Seed 2.0 Lite 提炼要点 |
| `AP.IMPACT` / `AP.visualPrompt()` / `impactLayer` | 系统提示词"视觉冲击力"条款 + 图像提示词后缀 + 渲染引擎冲击力层 + 质检"冲击力检查" |
| `AP.mockPlan(prompt, ctx)` | `ModelGateway.plan()` → 豆包 Seed 2.0 Pro（备：Qwen3.5 Plus），JSON Schema 约束输出 |
| `AP.mockRefine(spec, instr)` | `ModelGateway.refine()` → Seed 2.0 Lite 输出 JSON Patch |
| CSS 渐变 / 图案背景（`bgLayer`） | `ModelGateway.genImage()` → Seedream 5.0（备：Qwen-Image 2.0）生成无文字背景，按 `visual.prompt + seed` 缓存 |
| `AP.renderPoster()` | 同一份渲染代码：浏览器预览 + 服务端无头渲染导出 PNG |
| 生成过程步骤动画 | SSE 流式事件：understand / retrieve / plan / visual / render / qa |
| `localStorage` 模板 | `poster_template` 表，企业 / 团队 / 平台三级 |
