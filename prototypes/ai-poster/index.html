生成与微调流程

生成：提示词 + 素材缩略图 + 品牌 Kit → Seed 2.0 Pro 输出设计 JSON（场景 / 版式 / 配色 / 文案 / 选图 / 视觉 prompt）→ Seedream 5.0 生成无文字背景 → 渲染引擎排版文案、电话、二维码、Logo → 质检（溢出 / 对比度 / 敏感词 / 内容安全）。
微调：当前设计 JSON + 用户指令 → Seed 2.0 Lite 输出 JSON Patch → 引擎即时重渲染（<0.5s）；仅当涉及风格 / 背景 / 画幅变化时才调用图像模型重绘或扩图。每次生成 / 微调保留一个版本，可撤销、可从任一版本分支。

模型选型（2026-09，国内合规优先，一主一备可路由）

理解 / 设计：豆包 Seed 2.0 Pro多模态（看素材图）、JSON Schema 结构化输出、中文文案强；与 Seedream 同平台（火山引擎）。备选：通义 Qwen3.5 Plus（阿里云百炼）。
微调 / 文案：Seed 2.0 Lite高频、低延迟、¥0.6/3.6 每百万 tokens；纯文本改写可用 DeepSeek V4 Flash 进一步降本。
视觉生成：Seedream 5.0中文语境设计感最像成稿、局部编辑强、国内合规可备案。备选：Qwen-Image 2.0（局部编辑最强、可私有化）。
可选后端：Nano Banana Pro / GPT Image 2中文文字渲染与小字准确率业界最高，适合海外版或"整图创意模式"；国内主链路不依赖境外模型。
